# 📦 Capacity-Constrained DP (Dictionary-based Knapsack)

## 🧠 문제 개요

* 최대 허용 값 `D`가 주어짐
* `P`개의 선택지가 순차적으로 주어짐
* 각 선택지는 `(x, y)` 형태

  * `x`: 비용 / 소모량
  * `y`: 해당 선택지의 가치
* 여러 선택지를 조합해서 **총 비용이 정확히 `D`가 되도록** 만들 때
  👉 **가능한 최대 최소 가치**를 구하는 문제

핵심은 **조합된 선택지들 중 가장 작은 y 값을 최대화**하는 것.

---

## 💡 접근 아이디어

### 🔑 상태 정의

```python
dp[k] = 비용 합이 k일 때 가능한 최대 "최소 가치"
```

* `k` : 현재까지의 비용 합
* 값 : 해당 조합에서의 **최소 y 값**
* `dict`를 쓰는 이유
  → 비용 `D`까지 전부 배열로 만들 필요 없이 **도달 가능한 상태만 관리**

---

### 🔄 상태 전이

각 `(x, y)`를 하나씩 처리하면서 새로운 `dp`를 만든다.

1. **현재 선택지를 단독으로 선택**

```python
new_dp[x] = y
```

2. **기존 상태 유지**

```python
new_dp[k] = max(new_dp.get(k, 0), v)
```

3. **기존 상태 + 현재 선택지**

```python
new_dp[k + x] = max(
    new_dp.get(k + x, 0),
    min(v, y)
)
```

👉 `min(v, y)`
→ 여러 개를 선택하면 **가치는 가장 작은 값이 결정**되기 때문

---

## 🧪 전체 코드

```python
D, P = map(int, input().split())

dp = {}

for _ in range(P):
    new_dp = {}

    x, y = map(int, input().split())
    new_dp[x] = y

    for k, v in dp.items():
        # 기존 상태 유지
        if k in new_dp:
            new_dp[k] = max(new_dp[k], v)
        else:
            new_dp[k] = v

        # 현재 선택지 추가
        if k + x <= D:
            if k + x in new_dp:
                new_dp[k + x] = max(new_dp[k + x], min(v, y))
            else:
                new_dp[k + x] = min(v, y)

    dp = new_dp

print(dp[D])
```

---

## ⏱️ 시간 복잡도

* 최악의 경우

  * 각 선택지마다 `dp`의 모든 상태를 순회
* **O(P × S)**

  * `S`: dp에 존재하는 상태 수 (최대 `D`)

👉 배열 DP보다 실제로는 훨씬 작게 유지됨

---

## 🧠 공간 복잡도

* **O(S)**
  (`dict`에 저장된 상태 수만큼)

---

## ✨ 이 풀이의 포인트

* ✔ 배열 DP 대신 `dict DP` → 메모리 절약
* ✔ `min → max` 구조로 **"최소값을 최대화"** 하는 DP
* ✔ 순차 처리라 선택 순서에 의존하지 않음
