# 🧮 BOJ — 세 수의 합(0 만들기) / Two-Pointer with Duplicates Handling

이 코드는 정렬된 배열에서 **i번째 원소를 기준으로**, 나머지 두 수를 투 포인터로 탐색하여
`a + b + c = 0`을 만족하는 **(a, b, c) 조합의 개수**를 구하는 방식이다.

중복된 값이 존재할 수 있으므로,
**같은 숫자가 여러 개 있는 경우의 조합 수를 정확히 계산하는 로직**이 핵심 포인트!

---

## 🚀 알고리즘 핵심 아이디어

1. 배열을 정렬한다.
2. 각 `i`에 대해:

   * `target = candidates[i]`
   * `left = i + 1`, `right = N - 1` 로 두 포인터를 시작
3. `candidates[left] + candidates[right] + target` 값을 비교하여

   * 0이면 조합을 계산하여 `result`에 누적
   * 0보다 크면 right 감소
   * 0보다 작으면 left 증가
4. **중복값(lval == rval 또는 동일 값이 여러 개 존재)** 처리 시 조합 계산을 정확히 수행

---

## ✨ 중복 처리 방식 설명

### ✔ Case 1: `lval == rval`

예: `[ -3, 1, 1, 1, 1 ]` 처럼
같은 값 여러 개가 남아있는 경우

* left ~ right 사이의 개수 = `count`
* 중복 조합 = `count * (count - 1) // 2`

### ✔ Case 2: 서로 다른 값이지만 중복됨

예: left 쪽에 1이 3개, right 쪽에 2가 2개라면
→ 조합 수 = `3 * 2 = 6`

---

## 🧩 전체 코드 (정리된 버전)

```python
N = int(input())
candidates = list(map(int, input().split()))
candidates.sort()


def two_pointer(curr_idx):
    target = candidates[curr_idx]
    left = curr_idx + 1
    right = N - 1
    result = 0

    while left < right:
        # 현재 index는 제외
        if left == curr_idx:
            left += 1
            continue
        if right == curr_idx:
            right -= 1
            continue

        lval = candidates[left]
        rval = candidates[right]
        total = lval + rval + target

        # 합이 0인 경우
        if total == 0:
            # 같은 값이 여러 개 있는 케이스
            if lval == rval:
                count = right - left + 1
                result += count * (count - 1) // 2
                break
            else:
                # 각각 몇 개씩 중복인지 센다
                left_count = 1
                right_count = 1

                while left + 1 < right and candidates[left + 1] == lval:
                    left_count += 1
                    left += 1

                while left < right - 1 and candidates[right - 1] == rval:
                    right_count += 1
                    right -= 1

                result += left_count * right_count
                left += 1
                right -= 1

        # 합이 양수 → 감소
        elif total > 0:
            right -= 1
        # 합이 음수 → 증가
        else:
            left += 1

    return result


answer = 0
for i in range(N):
    answer += two_pointer(i)

print(answer)
```

---

## ⏱ 시간 복잡도

| 단계                  | 복잡도        |
| ------------------- | ---------- |
| 정렬                  | O(N log N) |
| 각 i에 대해 two-pointer | O(N)       |
| 전체                  | **O(N²)**  |

N 최대 약 10000까지 충분히 가능하며,
중복 처리까지 가장 효율적인 방식이다.

---

## 📌 요약

* 정렬 후 i번째 값 선택
* 나머지 두 값은 투 포인터로 탐색
* 중복된 값의 개수를 조합으로 계산하는 것이 핵심
* 전체 시간복잡도는 O(N²)
