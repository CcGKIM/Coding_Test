# 💡 발전소 전력 커버리지 최소값 구하기 (최적 발전 수치 문제)

## 📌 문제 개요

구름 나라는 `N`개의 도시와 `M`개의 양방향 도로로 구성되어 있습니다.  
이 중 `K`개의 도시에 발전소가 설치되어 있으며,  
각 발전소는 거리 `X` 이내의 구간에 전력을 공급할 수 있습니다.

**목표는 모든 도시와 도로 상의 모든 지점이 전력을 공급받도록 하는 최소 발전 수치 X를 구하는 것입니다.**

---

## 🎯 핵심 아이디어

도로 `(u, v)`의 길이가 `w`일 때, 발전소에서 도시 `u`와 `v`까지 도달한 거리 `du`, `dv`가 있다면:

```
(전력 범위 X - du) + (X - dv) ≥ w
```

정리하면:

```
2 * X ≥ du + dv + w
→ X ≥ (du + dv + w) / 2
```

이를 만족하는 **최소의 X**를 이분 탐색으로 구합니다.

---

## 📚 알고리즘 요약

1. 다익스트라로 발전소 → 각 도시까지의 최단 거리 계산
2. 이분 탐색으로 가능한 발전 수치 X를 결정
3. X가 주어졌을 때 위 조건을 만족하는지 `is_covered(X)`로 판단

---

## 🧠 핵심 함수 설명

### 🔧 `dijkstra(my_plants)`

- 다익스트라 알고리즘으로 발전소들에서 각 도시까지의 최소 거리 계산

### 🔧 `is_covered(X)`

- 모든 도로에 대해 `2X >= du + dv + w` 조건을 만족하는지 확인

---

## ✅ 전체 코드

```python
from collections import defaultdict
import heapq

# 입력 처리
N, M, K = map(int, input().split())
plants = list(map(int, input().split()))
max_length = 0

routes = []
tree = defaultdict(list)

for _ in range(M):
    a, b, c = map(int, input().split())
    tree[a].append((b, c))
    tree[b].append((a, c))
    routes.append((a, b, c))
    max_length = max(max_length, c)

# 다익스트라: 발전소들로부터 거리 계산
def dijkstra(my_plants):
    heap = []
    distance = [float('inf')] * (N + 1)

    for plant in my_plants:
        heapq.heappush(heap, (0, plant))
        distance[plant] = 0

    while heap:
        dist, node = heapq.heappop(heap)
        if dist > distance[node]:
            continue

        for to, cost in tree[node]:
            if dist + cost < distance[to]:
                distance[to] = dist + cost
                heapq.heappush(heap, (dist + cost, to))

    return distance

plant_distance = dijkstra(plants)

# 발전 수치 X로 모든 도로 커버 가능한지 확인
def is_covered(cover):
    for u, v, length in routes:
        if plant_distance[u] == float('inf') or plant_distance[v] == float('inf'):
            return False

        if 2 * cover < plant_distance[u] + plant_distance[v] + length:
            return False

    return True

# 이분 탐색으로 최소 발전 수치 찾기
left = 1
right = max(plant_distance[1:]) + max_length
answer = right

while left <= right:
    mid = (left + right) // 2
    if is_covered(mid):
        answer = mid
        right = mid - 1
    else:
        left = mid + 1

print(answer)
```


## 📌 시간 복잡도

- 다익스트라: `O((N + M) log N)`
- 이분 탐색: `log(max 거리)` ≒ 30
- 총 시간: 매우 효율적

## ✅ 요약

- 도로 전체를 커버하기 위한 정확한 조건을 활용
- 다익스트라 + 이분 탐색 결합
- 실수 오차 방지를 위해 모든 수식을 `*2` 해서 정수 처리
