# 프로그래머스 SQL - 입양 시각 구하기(1)

## 문제 링크
프로그래머스 > SELECT > 입양 시각 구하기(1)

## 문제 설명
동물 보호소에서 9시부터 19시까지, 각 시간대별로 입양이 몇 건이나 발생했는지 조회하는 문제.

### 조건
- 결과는 시간대 순으로 정렬
- 시간대: 9시 ~ 19시 (9 ≤ HOUR ≤ 19)

## 테이블 구조

### ANIMAL_OUTS
| Column | Type | Description |
|--------|------|-------------|
| ANIMAL_ID | VARCHAR | 동물 ID |
| ANIMAL_TYPE | VARCHAR | 동물 종류 |
| DATETIME | DATETIME | 입양 날짜 및 시간 |
| NAME | VARCHAR | 동물 이름 |
| SEX_UPON_OUTCOME | VARCHAR | 성별 및 중성화 여부 |

## 핵심 포인트

### 1. HOUR 함수 사용
```sql
HOUR(DATETIME)  -- DATETIME에서 시간만 추출 (0~23)
```

### 2. 서브쿼리를 통한 시간 추출
- 먼저 모든 입양 기록에서 시간대를 추출
- 추출한 시간대를 외부 쿼리에서 필터링 및 집계

### 3. WHERE vs HAVING
- `WHERE`: GROUP BY 전에 필터링 (개별 행 대상)
- `HAVING`: GROUP BY 후에 필터링 (그룹 대상)
- 이 문제에서는 시간대 필터링이므로 `WHERE` 사용

## 코드

```sql
SELECT a.HOUR, COUNT(*) AS COUNT
FROM (
    SELECT HOUR(DATETIME) AS HOUR
    FROM ANIMAL_OUTS
) a
WHERE 9 <= a.HOUR AND a.HOUR <= 19
GROUP BY a.HOUR
ORDER BY a.HOUR;
```

## 코드 설명

### 1. 서브쿼리 (FROM절)
```sql
SELECT HOUR(DATETIME) AS HOUR
FROM ANIMAL_OUTS
```
- 모든 입양 기록에서 시간만 추출
- 예: '2018-01-22 14:32:58' → 14

### 2. 필터링 (WHERE절)
```sql
WHERE 9 <= a.HOUR AND a.HOUR <= 19
```
- 9시 ~ 19시 사이의 데이터만 선택

### 3. 그룹화 및 집계 (GROUP BY)
```sql
GROUP BY a.HOUR
```
- 시간대별로 그룹화
- `COUNT(*)`로 각 시간대의 입양 건수 집계

### 4. 정렬 (ORDER BY)
```sql
ORDER BY a.HOUR
```
- 시간대 순으로 정렬 (오름차순)

## 다른 풀이 방법

### 방법 1: 서브쿼리 없이
```sql
SELECT HOUR(DATETIME) AS HOUR, COUNT(*) AS COUNT
FROM ANIMAL_OUTS
WHERE HOUR(DATETIME) BETWEEN 9 AND 19
GROUP BY HOUR(DATETIME)
ORDER BY HOUR;
```

### 방법 2: HAVING 사용 (비효율적)
```sql
SELECT HOUR(DATETIME) AS HOUR, COUNT(*) AS COUNT
FROM ANIMAL_OUTS
GROUP BY HOUR(DATETIME)
HAVING HOUR BETWEEN 9 AND 19
ORDER BY HOUR;
```
- `HAVING`은 그룹화 후 필터링이므로 불필요한 그룹화 발생
- `WHERE`가 더 효율적

## 배운 점
1. **HOUR() 함수**: DATETIME에서 시간 추출
2. **서브쿼리 활용**: 가독성 향상 및 단계별 처리
3. **WHERE vs HAVING**: 적절한 필터링 시점 선택
4. **GROUP BY + COUNT**: 시간대별 집계
