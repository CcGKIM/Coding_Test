# 문자열 변환 최소 횟수

## 문제 설명

문자열 A를 B로 변환하기 위한 최소 연산 횟수를 구하는 프로그램입니다.

**연산:** A의 한 글자를 선택하여 문자열의 맨 앞으로 이동

## 알고리즘

### 핵심 아이디어

**역방향 매칭 (Backward Matching)**

- B의 뒤에서부터 확인하면서 A에서 같은 순서로 나타나는 최대 길이를 찾습니다
- 매칭되지 않은 부분만 앞으로 이동하면 됩니다
- **답 = 전체 길이 - 매칭된 개수**

### 시간 복잡도

- `O(N)` : 두 포인터가 각각 한 번씩만 순회

## 예제

### Example 1
```
Input:
ABCD
CDAB

Process:
B의 뒤: ...A B
A에서:  A B C D
        ↑ ↑
매칭: 2개 (AB)

Output:
2
```

### Example 2
```
Input:
BAAB
AABB

Process:
B: A A B B
   ↓ ↓ ↓ ↓
A: B A A B

B[3]='B' → A[3] 매칭
B[2]='B' → A[0] 매칭
B[1]='A' → 매칭 불가 (A[0]보다 앞에 'A' 없음)

매칭: 2개

Output:
2
```

### Example 3 (불가능한 경우)
```
Input:
ABC
DEF

Output:
-1
```

## 코드

```python
A: str = input()
B: str = input()

N, M = len(A), len(B)

# 길이가 다르면 불가능
if N != M:
    print(-1)
    exit()

left = N - 1   # A의 포인터 (뒤에서부터)
right = N - 1  # B의 포인터 (뒤에서부터)

# 문자 구성이 같은지 확인
if sorted(list(A)) == sorted(list(B)):
    matched = 0

    while 0 <= right:
        right_letter = B[right]

        # A에서 right_letter와 매칭되는 문자 찾기
        while 0 <= left:
            left_letter = A[left]
            if left_letter == right_letter:
                matched += 1
                right -= 1
                left -= 1
                break
            else:
                left -= 1

        # A를 모두 확인했으면 종료
        if left < 0:
            break

    print(N - matched)
else:
    print(-1)
```

## 주요 로직

1. **유효성 검사**
   - 길이 확인: `len(A) != len(B)` → `-1`
   - 문자 구성 확인: `sorted(A) != sorted(B)` → `-1`

2. **투 포인터 매칭**
   - `right`: B를 뒤에서부터 순회
   - `left`: A를 뒤에서부터 순회하며 매칭 찾기
   - 매칭 성공 시 두 포인터 모두 이동

3. **결과 계산**
   - 이동 횟수 = `N - matched`

## 최적화 포인트

- ✅ Two Pointer로 O(N) 달성
- ✅ 조기 종료 조건 (`left < 0`)
- ✅ 불가능한 케이스 먼저 필터링
