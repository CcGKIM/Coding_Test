# 🧩 문자열 함수 기반 그룹핑 (SQL)

## 📌 문제 개요

`PRODUCT` 테이블에서

* `PRODUCT_CODE`의 **앞 2글자**를 카테고리로 사용하여
* 카테고리별 상품 개수를 구하는 문제

---

## ✅ 사용한 쿼리 (MySQL 기준)

```sql
SELECT 
    MID(PRODUCT_CODE, 1, 2) AS CATEGORY,
    COUNT(*) AS PRODUCTS
FROM PRODUCT
GROUP BY CATEGORY
ORDER BY CATEGORY;
```

---

## 🧠 쿼리 설명

### 1️⃣ `MID(PRODUCT_CODE, 1, 2)`

* 문자열 `PRODUCT_CODE`의 **1번째 문자부터 2글자 추출**
* 예시:

  * `AB1234` → `AB`
  * `CD9999` → `CD`

👉 이 값을 `CATEGORY`로 사용

---

### 2️⃣ `GROUP BY CATEGORY`

* 같은 카테고리(앞 2글자)끼리 묶어서 집계

---

### 3️⃣ `COUNT(*)`

* 해당 카테고리에 속한 상품 개수 계산

---

### 4️⃣ `ORDER BY CATEGORY`

* 카테고리 기준 오름차순 정렬

---

## 📊 실행 예시

| PRODUCT_CODE |
| ------------ |
| AA1001       |
| AA1002       |
| BB2001       |
| CC3001       |

### 결과

| CATEGORY | PRODUCTS |
| -------- | -------- |
| AA       | 2        |
| BB       | 1        |
| CC       | 1        |

# 🔤 SQL 문자열 함수 정리 (DB별 비교)

## 1️⃣ 부분 문자열 추출

| DB             | 함수                                  | 예시                             |
| -------------- | ----------------------------------- | ------------------------------ |
| **MySQL**      | `MID(str, start, len)`              | `MID(code,1,2)`                |
| MySQL          | `SUBSTRING(str, start, len)`        | `SUBSTRING(code,1,2)`          |
| **PostgreSQL** | `SUBSTRING(str FROM start FOR len)` | `SUBSTRING(code FROM 1 FOR 2)` |
| PostgreSQL     | `LEFT(str, len)`                    | `LEFT(code,2)`                 |
| **MSSQL**      | `SUBSTRING(str, start, len)`        | `SUBSTRING(code,1,2)`          |
| MSSQL          | `LEFT(str, len)`                    | `LEFT(code,2)`                 |

💡 **이 문제에서 가장 범용적인 방식**

```sql
LEFT(PRODUCT_CODE, 2)
```

---

## 2️⃣ 문자열 길이

| DB         | 함수            |
| ---------- | ------------- |
| MySQL      | `LENGTH(str)` |
| PostgreSQL | `LENGTH(str)` |
| MSSQL      | `LEN(str)`    |

---

## 3️⃣ 문자열 결합

| DB         | 함수                     |   |                   |
| ---------- | ---------------------- | - | ----------------- |
| MySQL      | `CONCAT(a, b)`         |   |                   |
| PostgreSQL | `a                     |   | b`, `CONCAT(a,b)` |
| MSSQL      | `a + b`, `CONCAT(a,b)` |   |                   |

---

## 4️⃣ 대소문자 변환

| 함수           | 설명  |
| ------------ | --- |
| `UPPER(str)` | 대문자 |
| `LOWER(str)` | 소문자 |

(MySQL / PostgreSQL / MSSQL 공통)

---

## 5️⃣ 문자열 치환

| DB | 함수                   | 예시                     |
| -- | -------------------- | ---------------------- |
| 공통 | `REPLACE(str, a, b)` | `REPLACE(code,'-','')` |

---

## 🧠 DB별 권장 리팩토링 쿼리

### ✅ MySQL / PostgreSQL / MSSQL 공통 (가장 안전)

```sql
SELECT 
    LEFT(PRODUCT_CODE, 2) AS CATEGORY,
    COUNT(*) AS PRODUCTS
FROM PRODUCT
GROUP BY LEFT(PRODUCT_CODE, 2)
ORDER BY CATEGORY;
```

---

## ⚠️ 주의 포인트 (실무 & 코테)

* `GROUP BY 별칭(CATEGORY)`

  * **MySQL**: 가능
  * **PostgreSQL / MSSQL**: ❌ 불가 → 표현식 그대로 써야 함

```sql
-- 안전한 방식
GROUP BY LEFT(PRODUCT_CODE, 2)
```

---

## ✨ 핵심 정리

* ✔ 문자열을 기준으로 그룹핑할 때는 **부분 문자열 함수**가 핵심
* ✔ `LEFT()`는 DB 호환성이 가장 좋음
* ✔ `GROUP BY`에서 **별칭 사용 여부는 DB마다 다름**
