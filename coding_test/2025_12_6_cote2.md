# 🌲 트리 DP 문제 풀이 (Python)

이 코드는 **루트를 0번 노드로 하는 트리에서, 각 노드의 처리 시간이 최소가 되도록 스케줄을 계산하는 DP 문제**를 해결한 파이썬 구현입니다.
주요 아이디어는 **자식 노드를 처리할 때, 시간이 오래 걸리는 순서대로 처리해야 전체 시간을 최소화할 수 있다**는 그리디 + DP 전략입니다.

---

## 📌 문제 개요

* 노드 0이 루트인 트리 구조가 주어짐
* `arr[i]`는 **i번 노드의 부모 노드**
* 각 노드에서 모든 자식 노드를 처리하는데 걸리는 최소 시간을 계산해야 함
* 자식 처리 순서는 자유롭게 선택할 수 있음
* 핵심은 **자식들의 처리 시간을 내림차순으로 정렬하여 큰 값부터 처리하는 것**

---

## 💡 핵심 아이디어 (DP + Greedy)

어떤 노드의 자식 처리 시간을 리스트로 모은 뒤:

1. 내림차순으로 정렬한다.
2. 가장 오래 걸리는 자식을 먼저 처리한다.
3. 각 자식에 대해 `(자식 처리시간 + 자신의 대기시간)` 을 계산한다.
4. 그 중 최댓값이 현재 노드의 처리 시간.

예시:
자식 처리 시간이 `[4, 2, 1]`이라면
처리 순서는 `4 → 2 → 1`이 최적이며, 계산은:

| 순서(idx) | 자식 처리시간 | 실제 걸리는 시간 = 처리시간 + (idx+1) |
| ------- | ------- | -------------------------- |
| 0       | 4       | 4 + 1 = 5                  |
| 1       | 2       | 2 + 2 = 4                  |
| 2       | 1       | 1 + 3 = 4                  |

따라서 부모 노드는 **5시간**이 필요함.

---

## 🧠 코드

```python
N = int(input())
arr = list(map(int, input().split()))
tree = [[] for _ in range(N)]

dp = [float('inf')] * N

# Build tree: arr[i] = parent of i
for i in range(N):
    if i == 0:
        continue
    parent = arr[i]
    tree[parent].append(i)

def tree_dp(node, visited):
    visited.add(node)
    result = []

    # DFS를 통해 자식들의 처리 시간 계산
    for child in tree[node]:
        if child not in visited:
            result.append(tree_dp(child, visited))

    # 처리 시간이 큰 자식부터 처리해야 전체 시간이 짧아진다
    result.sort(reverse=True)

    val = 0
    for idx, value in enumerate(result):
        # (자식 처리시간 + 자식이 처리되는 순서에서 기다리는 시간)
        val = max(val, (1 + idx) + value)

    dp[node] = min(dp[node], val)
    return dp[node]

visited = set()
tree_dp(0, visited)
print(dp[0])
```

## 📘 알고리즘 정리

* **DFS로 트리를 순회**
* 각 노드는 아래와 같은 값을 반환한다:

```
해당 노드를 루트로 하는 서브트리 전체를 처리하는 데 필요한 최소 시간
```

* 자식 노드의 DP 값들을 모아 정렬 → 그리디한 순서 결정
* 최종적으로 루트(0번 노드)의 처리 시간을 출력
