# 🐾 입양 시각이 가장 오래 걸린 동물 2마리

## 📌 문제 요약

* 보호소에 들어온 동물 정보: `ANIMAL_INS`
* 보호소에서 나간(입양된) 동물 정보: `ANIMAL_OUTS`

각 동물에 대해
**`입소 시각 → 입양 시각`까지 걸린 시간이 가장 긴 동물 2마리**의
`ANIMAL_ID`, `NAME`을 조회하는 문제.

---

## 🧠 핵심 아이디어

1. **입소 + 입양 기록이 모두 있는 동물만 대상**

   * `ANIMAL_ID` 기준으로 `INNER JOIN`

2. **체류 시간 계산**

   * `입양 시각 - 입소 시각`
   * 오래 걸린 순서로 정렬 (`DESC`)

3. **상위 2마리만 조회**

   * `LIMIT 2`

---

## ✅ 최종 SQL

```sql
SELECT a.ANIMAL_ID, a.NAME
FROM ANIMAL_INS a
JOIN ANIMAL_OUTS b ON a.ANIMAL_ID = b.ANIMAL_ID
ORDER BY b.DATETIME - a.DATETIME DESC
LIMIT 2;
```

---

## 🔍 쿼리 해설

### 1️⃣ 테이블 조인

```sql
FROM ANIMAL_INS a
JOIN ANIMAL_OUTS b ON a.ANIMAL_ID = b.ANIMAL_ID
```

* `JOIN` → 입소 + 입양 기록이 **모두 존재하는 동물만 선택**
* 보호소에만 있고 아직 입양되지 않은 동물은 제외됨

---

### 2️⃣ 체류 시간 계산

```sql
b.DATETIME - a.DATETIME
```

* `ANIMAL_OUTS.DATETIME` : 입양 시각
* `ANIMAL_INS.DATETIME` : 입소 시각
* 두 시각의 차이 = **보호소 체류 시간**

> 💡 MySQL에서는 `DATETIME - DATETIME` 연산이 가능하며
> 내부적으로 시간 차이를 초 단위로 계산한다.

---

### 3️⃣ 정렬 + 상위 2개 제한

```sql
ORDER BY b.DATETIME - a.DATETIME DESC
LIMIT 2
```

* 체류 시간이 **긴 순서대로 정렬**
* 가장 오래 걸린 **2마리만 출력**

---

## ⏱ 실행 흐름 요약

```
입소 테이블
   ⬇ JOIN (ANIMAL_ID)
입양 테이블
   ⬇ 체류 시간 계산
내림차순 정렬
   ⬇
상위 2건 출력
```

---

## ⚠️ 주의할 점

* `LEFT JOIN` ❌ → 입양 안 된 동물까지 포함됨
* `ORDER BY DATETIME` ❌ → 시간 차이가 아닌 단순 시각 정렬
* 반드시 **시간 차이 기준 정렬**해야 함
