# 🚦 예산 제한 경로에서 최대 간선 비용 최소화

## 📌 문제 핵심 요약

* 시작 노드 `A` → 도착 노드 `B`
* 간선마다 비용 존재
* **총 비용 ≤ C**
* 그 조건을 만족하는 경로 중
  👉 **경로에서 사용한 간선 비용의 최댓값을 최소화**
* 불가능하면 `-1`

---

## 🧠 문제의 본질

이 문제는 **최단 거리 문제가 아님** ❌

우리가 최소화하려는 값은:

> ❌ 총 비용
> ⭕ **경로에서 가장 비싼 간선 비용**

하지만 동시에 **총 비용 제한(C)** 이 존재함.

그래서 단일 기준으로는 해결이 안 되고,
👉 **상태를 확장하거나 / 기준을 고정하고 검증**해야 한다.

---

# 1️⃣ 상태 기반 BFS 풀이 (기본 풀이)

## 💡 아이디어

상태를 이렇게 잡는다:

```text
(현재 노드, 지금까지 쓴 비용, 지금까지의 최대 간선 비용)
```

그리고 각 노드에 대해:

* "이 노드에 도달할 수 있는 최소 최대 간선 비용"만 기록

---

## 🧪 코드

```python
from collections import deque

N, M, A, B, C = map(int, input().split())

tree = [[] for _ in range(N + 1)]
visited = [float('inf')] * (N + 1)

for _ in range(M):
    x, y, money = map(int, input().split())
    tree[x].append((y, money))
    tree[y].append((x, money))

queue = deque()
queue.append((A, 0, 0))  # (node, total_cost, max_edge)

while queue:
    node, spend, max_edge = queue.popleft()

    if node == B:
        visited[B] = min(visited[B], max_edge)
        continue

    for nxt, cost in tree[node]:
        ns = spend + cost
        nm = max(max_edge, cost)

        if ns <= C and nm < visited[nxt]:
            visited[nxt] = nm
            queue.append((nxt, ns, nm))

print(-1 if visited[B] == float('inf') else visited[B])
```

---

## ⏱️ 복잡도

* 시간: `O(N + M)` (가지치기 덕분에 실질적으로 빠름)
* 공간: `O(N + M)`

# 2️⃣ ⭐ 이분 탐색 + BFS (가장 안정적 / 추천)

## 💡 핵심 발상

> "최대 간선 비용이 **X 이하**일 때,
> 총 비용 ≤ C 로 B에 도달 가능할까?"

👉 YES / NO 로 판별 가능
👉 그럼 **이분 탐색** 가능

---

## 🔁 구조

1. 간선 비용을 기준으로 이분 탐색
2. 특정 `mid` 이하의 간선만 사용
3. BFS/DFS로 총 비용 ≤ C 인지 확인

---

## 🧪 코드

```python
from collections import deque

N, M, A, B, C = map(int, input().split())

tree = [[] for _ in range(N + 1)]
edges = []

for _ in range(M):
    x, y, cost = map(int, input().split())
    tree[x].append((y, cost))
    tree[y].append((x, cost))
    edges.append(cost)

edges = sorted(set(edges))

def can_go(limit):
    queue = deque()
    queue.append((A, 0))
    dist = [float('inf')] * (N + 1)
    dist[A] = 0

    while queue:
        node, spend = queue.popleft()
        for nxt, cost in tree[node]:
            if cost > limit:
                continue
            ns = spend + cost
            if ns <= C and ns < dist[nxt]:
                dist[nxt] = ns
                queue.append((nxt, ns))

    return dist[B] != float('inf')

left, right = 0, len(edges) - 1
answer = float('inf')

while left <= right:
    mid = (left + right) // 2
    if can_go(edges[mid]):
        answer = edges[mid]
        right = mid - 1
    else:
        left = mid + 1

print(-1 if answer == float('inf') else answer)
```

---

## ⏱️ 복잡도

* BFS: `O(N + M)`
* 이분 탐색: `O(log M)`
* 전체:
  👉 **O((N + M) · log M)**

📌 **입력 크기 클수록 이 풀이가 가장 안정적**

# 3️⃣ 다익스트라 (상태 확장 버전)

## 💡 아이디어

다익스트라를 살짝 변형:

* 거리 = **지금까지의 최대 간선 비용**
* 단, 총 비용 ≤ C 인 경우만 허용

---

## 🧪 코드

```python
import heapq

N, M, A, B, C = map(int, input().split())

tree = [[] for _ in range(N + 1)]

for _ in range(M):
    x, y, cost = map(int, input().split())
    tree[x].append((y, cost))
    tree[y].append((x, cost))

dist = [float('inf')] * (N + 1)
heap = [(0, 0, A)]  # (max_edge, total_cost, node)
dist[A] = 0

while heap:
    max_edge, total, node = heapq.heappop(heap)

    if node == B:
        print(max_edge)
        exit()

    for nxt, cost in tree[node]:
        nt = total + cost
        nm = max(max_edge, cost)

        if nt <= C and nm < dist[nxt]:
            dist[nxt] = nm
            heapq.heappush(heap, (nm, nt, nxt))

print(-1)
```

---

## ⏱️ 복잡도

* 시간: `O(M log N)`
* 공간: `O(N + M)`

📌 구현은 직관적이지만,
상태 수가 많아지면 성능이 흔들릴 수 있음
