# 📘 SQL 예제 — 특정 카테고리 도서 조회

**BOOK · AUTHOR 테이블 조인 + 날짜 포맷 + 정렬**

## 📌 목적

* `BOOK` 테이블과 `AUTHOR` 테이블을 조인한다.
* 카테고리가 **경제(경제 분야)**인 책만 필터링한다.
* 출판일을 `YYYY-MM-DD` 형식으로 변환한다.
* 출판일 기준 오름차순(가장 오래된 책부터)으로 정렬한다.

---

## 🗂 SQL 코드

```sql
SELECT 
    b.BOOK_ID, 
    a.AUTHOR_NAME, 
    DATE_FORMAT(b.PUBLISHED_DATE, '%Y-%m-%d') AS PUBLISHED_DATE
FROM BOOK b
JOIN AUTHOR a 
    ON b.AUTHOR_ID = a.AUTHOR_ID
WHERE b.CATEGORY = '경제'
ORDER BY b.PUBLISHED_DATE ASC;
```

---

## 🔍 코드 해설

### 1. `SELECT`

조회할 컬럼을 지정:

* `BOOK_ID`: 책 고유 ID
* `AUTHOR_NAME`: 저자 이름 (`AUTHOR` 테이블에서 가져옴)
* `PUBLISHED_DATE`: MySQL의 `DATE_FORMAT`을 통해 `YYYY-MM-DD`로 변환

### 2. `FROM / JOIN`

```sql
FROM BOOK b
JOIN AUTHOR a ON b.AUTHOR_ID = a.AUTHOR_ID
```

* `BOOK` 테이블을 기준 테이블로 사용
* `AUTHOR_ID`를 기준으로 `AUTHOR` 테이블과 **INNER JOIN**

### 3. `WHERE`

```sql
WHERE b.CATEGORY = '경제'
```

* 책의 카테고리가 `'경제'`인 데이터만 필터링

### 4. `ORDER BY`

```sql
ORDER BY b.PUBLISHED_DATE ASC
```

* 출판 날짜 기준 **오름차순 정렬**

## 🎯 정리

이 SQL은

> “경제 카테고리의 책을 출판일이 오래된 순으로 정렬해
> 책 ID + 저자 이름 + 출판일을 조회하는 쿼리”

를 구현한 깔끔한 조인 + 날짜 포맷팅 예제다.
