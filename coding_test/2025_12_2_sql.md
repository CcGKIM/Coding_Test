# 🍨 재료 타입별 아이스크림 주문량 집계 SQL

이 SQL 문은 아이스크림 정보 테이블과
상반기 판매량 테이블을 조인하여 **재료 유형별 총 주문량(TOTAL_ORDER)** 을 계산하는 쿼리입니다.
---

## 📌 문제 요약

두 테이블이 존재한다고 가정:

### **1️⃣ ICECREAM_INFO**

| 컬럼명          | 설명                                   |
| --------------- | -------------------------------------- |
| FLAVOR          | 아이스크림 이름                        |
| INGREDIENT_TYPE | 재료 타입 (예: fruit, milk, chocolate) |

### **2️⃣ FIRST_HALF**

| 컬럼명      | 설명             |
| ----------- | ---------------- |
| FLAVOR      | 아이스크림 이름  |
| TOTAL_ORDER | 상반기 총 주문량 |

**목표:**
FLAVOR 기준으로 두 테이블을 조인하여,
각 **INGREDIENT_TYPE(재료 타입)** 별 총 판매량을 계산한다.

---

## 🧠 쿼리 설명

1. `FIRST_HALF` 와 `ICECREAM_INFO` 를
   **FLAVOR 컬럼으로 조인**

2. 조인된 데이터에서
   **INGREDIENT_TYPE(재료 타입)** 기준으로 그룹화 (GROUP BY)

3. 각 그룹별 `TOTAL_ORDER`를 합산 (SUM)

4. 합산된 주문량 기준으로 정렬 (ORDER BY)

---

## ✅ SQL 코드

```sql
SELECT
    info.INGREDIENT_TYPE,
    SUM(half.TOTAL_ORDER) AS TOTAL_ORDER
FROM FIRST_HALF half
JOIN ICECREAM_INFO info
    ON half.FLAVOR = info.FLAVOR
GROUP BY info.INGREDIENT_TYPE
ORDER BY SUM(half.TOTAL_ORDER);
```

---

## 📈 결과 예시 (가상의 예)

| INGREDIENT_TYPE | TOTAL_ORDER |
| --------------- | ----------- |
| milk            | 1520        |
| chocolate       | 1870        |
| fruit           | 2310        |

---

## 💡 추가 팁 — ORDER BY에서 별칭 사용 가능

아래처럼 `TOTAL_ORDER` 라는 별칭을 ORDER BY에서 사용해도 된다:

```sql
ORDER BY TOTAL_ORDER;
```

---

## ⚙️ 시간 복잡도 관점 (DB 내부 처리)

- 조인: `O(N log N)` ~ `O(N*M)`
- GROUP BY + SUM: `O(N)`
- ORDER BY: `O(G log G)` (G = 재료 타입 개수 → 매우 작음)

실제로는 매우 빠르게 처리되는 단순 aggregation 쿼리.
