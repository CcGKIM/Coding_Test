# 🐶 이름에 "EL"이 포함된 개 찾기 (SQL)

동물 보호소 데이터에서
**이름에 `EL`이 포함된 개(Dog)** 의 **ID와 이름**을
**이름 오름차순**으로 조회한다.

---

## 📌 문제 요구사항

* 동물 종류가 **Dog**
* 이름에 **EL 포함**
* 대소문자 구분 없이 검색
* 결과는 **이름 기준 오름차순 정렬**

---

## 🧠 핵심 아이디어

### 🔹 대소문자 구분 없는 문자열 검색

* `LIKE`는 DB 설정에 따라 대소문자를 구분할 수 있음
* 안전하게 처리하기 위해 `UPPER()` 사용

```sql
UPPER(NAME) LIKE '%EL%'
```

👉 이름을 모두 대문자로 바꾼 뒤 `"EL"` 포함 여부 확인

---

### 🔹 조건 필터링

```sql
ANIMAL_TYPE = 'Dog'
```

👉 개만 조회

---

### 🔹 정렬

```sql
ORDER BY NAME
```

👉 이름 기준 오름차순 정렬 (기본값 ASC)

---

## 🧩 전체 SQL 쿼리

```sql
SELECT ANIMAL_ID, NAME
FROM ANIMAL_INS
WHERE UPPER(NAME) LIKE '%EL%'
  AND ANIMAL_TYPE = 'Dog'
ORDER BY NAME;
```

---

## 📝 쿼리 실행 흐름

1. `ANIMAL_INS` 테이블 조회
2. 이름을 대문자로 변환
3. `"EL"` 이 포함된 이름만 필터링
4. 동물 타입이 `Dog` 인 행만 선택
5. 이름 기준으로 정렬
6. `ANIMAL_ID`, `NAME` 출력

---

## 💡 알아두면 좋은 포인트

### ✅ LIKE 패턴 정리

| 패턴     | 의미        |
| ------ | --------- |
| `%EL%` | 중간에 EL 포함 |
| `EL%`  | EL로 시작    |
| `%EL`  | EL로 끝     |

---

### ✅ DB별 대소문자 처리 차이

* **MySQL**: 기본 collation에 따라 대소문자 구분 안 할 수도 있음
* **Oracle / PostgreSQL**: 기본적으로 구분함
  ➡️ `UPPER()` / `LOWER()` 사용이 가장 안전

---

## ⏱ 성능 참고

* `UPPER(NAME)` 사용 시 **인덱스 사용 불가**
* 대용량 테이블에서는 성능 저하 가능
* 실무에서는:

  * 대소문자 무시 인덱스
  * `ILIKE` (PostgreSQL)
  * collation 설정
    등을 고려

---

## 🎯 정리 한 줄 요약

> **문자열 검색 시 대소문자 이슈를 피하려면 `UPPER + LIKE` 조합이 가장 안전하다.**
