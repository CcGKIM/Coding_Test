# 🖥️ 백준 10282 - 해킹 (Dijkstra)

## 📌 문제 요약

한 컴퓨터가 해킹되면, **의존 관계에 따라 다른 컴퓨터들이 일정 시간 후 감염**된다.
초기 해킹 컴퓨터가 주어질 때,

* **총 몇 대의 컴퓨터가 감염되는지**
* **마지막 컴퓨터가 감염되기까지 걸리는 최소 시간**

을 구하는 문제이다.

---

## 🔍 핵심 아이디어

* 감염 시간은 **가중치가 있는 최단 경로 문제**
* 한 컴퓨터가 감염되면 **의존 관계 방향으로만 전파**
* → **다익스트라(Dijkstra) 알고리즘** 사용

---

## 🔄 그래프 방향 주의 (중요 ⭐)

입력 형식:

```
a b s
```

의미:

> **b가 감염되면 s초 후 a가 감염됨**

즉, 그래프는 다음 방향으로 구성해야 한다.

```
b → a (가중치 s)
```

👉 이 문제에서 가장 많이 실수하는 부분

---

## 🧠 풀이 전략

1. 시작 컴퓨터 `c`를 시작점으로 설정
2. 감염 시간을 거리 배열로 관리
3. 우선순위 큐(힙)를 이용한 다익스트라 수행
4. 처음 감염되는 컴퓨터만 감염 수에 포함
5. 모든 감염 컴퓨터 중 **최대 감염 시간**을 정답으로 출력

---

## 💻 구현 코드

```python
import heapq

T = int(input())

for _ in range(T):
    n, d, c = map(int, input().split())

    tree = [[] for _ in range(n + 1)]
    distance = [float('inf')] * (n + 1)

    for _ in range(d):
        a, b, s = map(int, input().split())
        tree[b].append((a, s))  # b → a

    heap = []
    distance[c] = 0
    heapq.heappush(heap, (0, c))

    infected = 1  # 시작 컴퓨터 포함

    while heap:
        t, node = heapq.heappop(heap)

        if t > distance[node]:
            continue

        for child, cost in tree[node]:
            if t + cost < distance[child]:
                if distance[child] == float('inf'):
                    infected += 1

                distance[child] = t + cost
                heapq.heappush(heap, (t + cost, child))

    answer_time = max(
        distance[i] for i in range(1, n + 1) if distance[i] != float('inf')
    )

    print(infected, answer_time)
```

---

## ⏱️ 시간 복잡도

* 다익스트라:
  **O((N + D) log N)**
* 테스트 케이스 T개 → 충분히 통과 가능

---

## 💾 공간 복잡도

* 그래프 + 거리 배열:
  **O(N + D)**

---

## ✅ 포인트 정리

* ✔ 다익스트라 적용 문제
* ✔ 그래프 방향 설정이 핵심
* ✔ 감염 수는 **처음 방문할 때만 카운트**
* ✔ 힙 기반 최적화로 시간 초과 방지
