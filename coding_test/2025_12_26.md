# 🐉 드래곤 앤 던전 – 최소 최대 체력 구하기

## 📌 문제 요약

용사는 여러 개의 방을 순서대로 지나간다.

* **몬스터 방 (type = 1)**

  * 몬스터 공격력 `a`, 체력 `h`
  * 용사가 먼저 공격
  * 몬스터는 죽기 전까지 반격

* **회복 방 (type = 2)**

  * 공격력 증가 `a`
  * 체력 회복 `h` (최대 체력 초과 불가)

❓ **모든 방을 클리어할 수 있는 용사의 최소 최대 체력은 얼마인가?**

---

## 💡 핵심 아이디어

### 1️⃣ 최대 체력을 기준으로 "가능한지"를 판별

* 최대 체력 `H`가 주어졌을 때
* 모든 방을 시뮬레이션하며 **죽지 않고 통과 가능한지** 확인

👉 가능하면 더 작은 체력도 되는지 확인
👉 불가능하면 체력을 늘려야 함

➡ **이분 탐색(Binary Search)** 사용

---

## 🧠 전투 로직 핵심

### ✔️ 몬스터와의 전투

* 용사가 먼저 공격
* 몬스터 체력 `m_hp`, 용사 공격력 `h_atk`
* 필요한 공격 횟수:

```python
need_cnt = ceil(m_hp / h_atk)
```

* 몬스터는 **용사가 공격한 횟수 - 1번만 반격**
* 용사가 버틸 수 있는지 확인:

```text
(h_cur_hp > (need_cnt - 1) * m_atk)
```

---

## 🧪 시뮬레이션 함수

```python
def is_available(h_init_atk, h_max_hp):
    h_atk, h_cur_hp = h_init_atk, h_max_hp

    for t, a, h in room_info:
        if t == 1:  # 몬스터 방
            result, h_atk, h_cur_hp = battle(h_atk, h_cur_hp, a, h)
            if h_cur_hp <= 0:
                return False
        else:  # 회복 방
            h_atk, h_cur_hp = heal(h_atk, h_max_hp, h_cur_hp, a, h)

    return True
```

## 🔍 이분 탐색 구조

```python
left = 1
right = N * ((10**6 * 10**6) + 1)
answer = float('inf')

while left <= right:
    mid = (left + right) // 2

    if is_available(h_init_atk, mid):
        answer = min(answer, mid)
        right = mid - 1
    else:
        left = mid + 1

print(answer)
```

---

## ⏱ 시간 복잡도

* **시뮬레이션:** `O(N)`
* **이분 탐색:** `O(log MAX_HP)`
* **전체:**

  ```
  O(N log MAX_HP)
  ```

👉 `N ≤ 100,000`에서도 충분히 통과
