# 🌳 트리의 Giga Node & Branch 길이 계산 (DFS)

트리에서 **루트 R**을 기준으로

* 처음으로 **가지가 2개 이상 갈라지는 지점(Giga Node)**
* Giga Node에서 시작하는 **가장 긴 가지(branch) 길이**

를 계산하는 문제입니다.
---

## 📌 문제 핵심 요약

트리는 루트에서 시작하여 쭉 내려가다가 어느 시점에서 분기점이 나타난다.
이때:

### ✔ Giga Node

- 루트 R에서 아래로 내려가다가
- **처음으로 자식 노드가 2개 이상 등장하는 지점**

### ✔ Pillar Length (기둥 길이)

루트 → Giga Node까지의 거리

### ✔ Longest Branch (가지 길이)

Giga Node → Leaf(자식 없는 노드) 중
**가장 먼 리프까지의 거리**

### ✔ Giga Node가 없는 경우

트리가 일자 구조이면 전체가 기둥이고 가지는 0
(루트 → 리프가 바로 기둥)

---

## 🧠 알고리즘 접근

1. **DFS로 트리 탐색**

   - 각 노드까지의 누적 거리(`distance[]`)
   - 자식이 2개 이상인 최초 노드를 Giga Node로 기록
   - 자식이 0개인 노드를 Leaf로 기록

2. **DFS 종료 후**

   - 기둥 길이: `distance[giga_node]`
   - 가지 길이: `max(distance[leaf] - distance[giga_node])`

3. **Giga Node가 없다면**

   - 트리가 일자형 → 리프까지의 거리 = 기둥 길이, 가지 = 0

---

## 📁 전체 코드

```python
import sys
sys.setrecursionlimit(300000)

N, R = map(int, input().split())

max_node = 1
edges = []

# 입력 저장 & max_node 계산
for _ in range(N - 1):
    x, y, dist = map(int, input().split())
    edges.append((x, y, dist))
    max_node = max(max_node, x, y)

# 인접 리스트
tree = [[] for _ in range(max_node + 1)]
for x, y, dist in edges:
    tree[x].append((y, dist))
    tree[y].append((x, dist))

leaf_nodes = []
giga_nodes = []
distance = [0] * (max_node + 1)

def dfs(node, parent, dist):
    distance[node] = dist

    child_count = 0
    for child, cost in tree[node]:
        if child != parent:
            child_count += 1

    # Giga Node 찾기: 첫 번째 분기점
    if not giga_nodes and child_count >= 2:
        giga_nodes.append(node)

    # Leaf Nodes
    if child_count == 0:
        leaf_nodes.append(node)

    for child, cost in tree[node]:
        if child != parent:
            dfs(child, node, dist + cost)

# DFS 실행
dfs(R, -1, 0)

# 결과 계산
if giga_nodes:
    giga_node = giga_nodes[0]

    branch = 0
    for leaf in leaf_nodes:
        branch = max(branch, distance[leaf] - distance[giga_node])

    print(distance[giga_node], branch)

else:
    # 일자 트리인 경우
    giga_node = leaf_nodes[0]
    print(distance[giga_node], 0)
```

## ✨ 개선된 깔끔 버전 (권장)

```python
import sys
sys.setrecursionlimit(300000)

N, R = map(int, input().split())
tree = [[] for _ in range(N + 1)]

for _ in range(N - 1):
    x, y, d = map(int, input().split())
    tree[x].append((y, d))
    tree[y].append((x, d))

distance = [0] * (N + 1)
giga = None
leaves = []

def dfs(node, parent):
    global giga

    child_count = 0
    for nxt, cost in tree[node]:
        if nxt != parent:
            child_count += 1

    # Giga Node: 첫 분기점
    if giga is None and child_count >= 2:
        giga = node

    # Leaf
    if child_count == 0:
        leaves.append(node)

    for nxt, cost in tree[node]:
        if nxt != parent:
            distance[nxt] = distance[node] + cost
            dfs(nxt, node)

dfs(R, -1)

if giga:
    pillar = distance[giga]
    branch = max(distance[leaf] - distance[giga] for leaf in leaves)
    print(pillar, branch)
else:
    leaf = leaves[0]
    print(distance[leaf], 0)
```

---

## 🧩 시간 복잡도

- DFS 한 번 → **O(N)**
- 가지 길이 계산 → 최대 리프 수 만큼 → **O(N)**
  전체 시간: **O(N)**
  트리 문제라 최적.

## 📌 정리

| 개념      | 의미                           |
| --------- | ------------------------------ |
| Giga Node | 처음으로 자식 수 ≥ 2인 노드    |
| Pillar    | 루트 → Giga Node 거리          |
| Branch    | Giga Node → 가장 먼 Leaf 거리  |
| 일자 트리 | Giga Node 없음 → 전체가 Pillar |
