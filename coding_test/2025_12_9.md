# 🚀 특정 두 정점을 반드시 지나야 하는 최단 경로 (Dijkstra)

이 코드는 **백준 1504번 – 특정한 최단 경로** 문제를 풀이한 것으로,
1번에서 N번 노드로 이동할 때 **두 정점 v1, v2를 반드시 거쳐야 하는 최단 경로**를 구한다.

경로는 두 가지 경우 중 더 작은 값을 선택한다:

* 경로 1: `1 → v1 → v2 → N`
* 경로 2: `1 → v2 → v1 → N`

Dijkstra 알고리즘을 세 번 실행하여 각 구간의 최단 거리를 구한다.

---

## 📌 접근 방식

1. **그래프 입력**을 받고 인접 리스트로 구성한다.
2. **Dijkstra 함수 구현**

   * 시작 정점에서 모든 정점까지의 최소 비용 배열을 반환
3. 총 3번의 다익스트라 실행

   * `dijkstra(1)`
   * `dijkstra(v1)`
   * `dijkstra(v2)`
4. 두 가지 경로 경우를 계산
5. 가능한 경로 중 최솟값 출력

   * 경로가 존재하지 않으면 `-1`

---

## 🧠 핵심 아이디어

Dijkstra는 "한 정점에서 다른 모든 정점까지의 최단 거리"를 구하기 때문에,

* `1 → v1`
* `v1 → v2`
* `v2 → N`

처럼 **각 구간을 독립적으로 계산해서 이어붙이는 방식**이 가능하다.

---

## 🧩 코드

```python
import heapq

N, E = map(int, input().split())
tree = [[] for _ in range(N + 1)]

# 양방향 그래프 구성
for _ in range(E):
    a, b, c = map(int, input().split())
    tree[a].append((b, c))
    tree[b].append((a, c))

v1, v2 = map(int, input().split())

def dijkstra(start):
    INF = float('inf')
    distance = [INF] * (N + 1)
    heap = []

    distance[start] = 0
    heapq.heappush(heap, (0, start))

    while heap:
        dist, node = heapq.heappop(heap)

        if dist > distance[node]:
            continue

        for next_node, cost in tree[node]:
            new_cost = dist + cost
            if new_cost < distance[next_node]:
                distance[next_node] = new_cost
                heapq.heappush(heap, (new_cost, next_node))

    return distance

# 다익스트라 3번 실행
one = dijkstra(1)
two = dijkstra(v1)
three = dijkstra(v2)

# 경로 1: 1 -> v1 -> v2 -> N
first = one[v1] + two[v2] + three[N]

# 경로 2: 1 -> v2 -> v1 -> N
second = one[v2] + three[v1] + two[N]

answer = min(first, second)

# 경로가 불가능한 경우
print(answer if answer != float('inf') else -1)
```

---

## ⏱ 시간 복잡도

Dijkstra 한 번의 시간복잡도는:

```
O(E log N)
```

이 코드는 총 3번 실행하므로:

```
O(3E log N) → O(E log N)
```

---

## 💾 공간 복잡도

* 그래프 저장: `O(E)`
* 거리 배열: `O(N)`

총합:

```
O(N + E)
```
