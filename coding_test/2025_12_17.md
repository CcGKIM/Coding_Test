# 🧠 다익스트라 + 그리디로 최소 방문 일수 구하기

## 📌 문제 핵심

* 시작 정점 `Y`에서 출발
* 그래프의 **모든 정점**을 방문해야 함
* **하루에 이동 가능한 최대 거리 `X`**
* 하루가 끝나면 **반드시 시작 정점 `Y`로 복귀**
* 하루에 여러 정점 방문 가능
* 목표: **모든 정점을 방문하는 최소 일수**

---

## 💡 핵심 아이디어

### 1️⃣ 다익스트라는 거리 계산용

* 시작 정점 `Y`에서 모든 정점까지의 **최단거리 `dist[v]`** 계산
* 시작점이 고정이므로 **다익스트라는 한 번만 수행**

---

### 2️⃣ 정점 하나의 최소 비용은 `2 × dist[v]`

하루의 이동은 항상 다음 형태:

```
Y → (여러 정점) → Y
```

따라서 정점 `v`를 방문하려면 최소한:

* `Y → v` : `dist[v]`
* `v → Y` : `dist[v]`

👉 **정점 v의 하루 최소 소비 거리 = `2 × dist[v]`**

---

### 3️⃣ 문제의 본질은 스케줄링 (그리디)

문제는 다음과 같이 바뀐다:

> 비용이 `2 × dist[v]` 인 작업들을
> 하루 용량 `X` 안에
> 최소 며칠에 나눠 처리할 것인가?

→ **가까운 정점부터 그리디하게 묶는 것이 최적**

---

## ❌ 불가능한 경우

가장 먼 정점조차 하루에 왕복할 수 없다면:

```
2 × max(dist) > X
```

👉 **정답은 -1**

---

## 🛠️ 풀이 절차

1. 다익스트라로 `dist[]` 계산
2. 시작 정점 `Y` 제외
3. 거리 오름차순 정렬
4. `2 × dist`를 하루 한계 `X`까지 채우며 일수 계산

---

## ✅ 파이썬 구현

```python
import heapq

N, M, X, Y = map(int, input().split())
tree = [[] for _ in range(N)]

for _ in range(M):
    a, b, c = map(int, input().split())
    tree[a].append((b, c))
    tree[b].append((a, c))


def dijkstra(start):
    dist = [float('inf')] * N
    dist[start] = 0
    heap = [(0, start)]

    while heap:
        cur_dist, node = heapq.heappop(heap)
        if cur_dist > dist[node]:
            continue

        for nxt, cost in tree[node]:
            nd = cur_dist + cost
            if nd < dist[nxt]:
                dist[nxt] = nd
                heapq.heappush(heap, (nd, nxt))

    return dist


distance = dijkstra(Y)
distance = [d for i, d in enumerate(distance) if i != Y]
distance.sort()

# 불가능한 경우
if max(distance) * 2 > X:
    print(-1)
    exit()

day = 1
curr = 0

for d in distance:
    cost = 2 * d
    if curr + cost <= X:
        curr += cost
    else:
        day += 1
        curr = cost

print(day)
```

---

## ⏱️ 시간 & 공간 복잡도

| 항목           | 복잡도              |
| ------------ | ---------------- |
| 다익스트라        | `O(M log N)`     |
| 정렬           | `O(N log N)`     |
| 그리디          | `O(N)`           |
| **총 시간 복잡도** | **`O(M log N)`** |
| 공간 복잡도       | `O(N + M)`       |
