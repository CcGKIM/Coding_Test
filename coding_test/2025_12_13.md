# 🔐 도어락 비밀번호 경우의 수 계산

## 📌 문제 요약

* 버튼은 `1 ~ B`까지 총 `B (1 ≤ B ≤ 11)`개
* 비밀번호는 **하나 이상의 버튼 조합**으로 구성
* 하나의 조합에서는 여러 버튼을 **동시에** 누를 수 있음
* **같은 버튼은 여러 조합에서 사용할 수 없음**
* **조합의 순서가 다르면 다른 비밀번호**

👉 주어진 `B`에 대해 **가능한 모든 비밀번호의 개수**를 구하는 문제

---

## 💡 핵심 아이디어

이 문제는 다음 두 단계로 분리해서 생각하면 깔끔하게 해결된다.

### 1️⃣ 버튼을 **몇 개 사용할지 선택**

* 전체 `B`개 중에서 `k (1 ≤ k ≤ B)`개만 사용할 수 있음

### 2️⃣ 선택한 `k`개 버튼을 **순서 있는 조합들로 분할**

* 버튼들을 겹치지 않는 여러 조합으로 나누고
* 조합들의 **순서까지 고려**

---

## 🧠 핵심 개념: Fubini 수 (Ordered Bell Numbers)

`dp[k]`
→ **k개의 버튼을 전부 사용해서 만들 수 있는 비밀번호의 수**

점화식은 다음과 같다:

```
dp[0] = 1
dp[k] = Σ (j = 1 ~ k) [ C(k, j) × dp[k - j] ]
```

### 의미

* 첫 번째 조합에 들어갈 버튼을 `j`개 선택 (`C(k, j)`)
* 나머지 `k - j`개 버튼으로 나머지 비밀번호 구성 (`dp[k-j]`)
* 가능한 모든 `j`에 대해 합산

---

## 🧮 전체 정답 계산

버튼을 `i`개 사용하는 경우:

* 버튼 선택: `C(B, i)`
* 비밀번호 구성: `dp[i]`

따라서 전체 정답은:

```
Answer = Σ (i = 1 ~ B) [ C(B, i) × dp[i] ]
```

---

## 🧑‍💻 파이썬 구현 코드

```python
import math

N = int(input())

for _ in range(N):
    B = int(input())
    dp = [0] * (B + 1)

    # dp[i]: i개의 버튼을 전부 사용해서 만들 수 있는 비밀번호 수
    dp[0] = 1

    # Fubini 수 계산
    for i in range(1, B + 1):
        for j in range(1, i + 1):
            dp[i] += math.comb(i, j) * dp[i - j]

    # 전체 버튼 B개 중 i개를 선택하는 경우까지 포함
    answer = 0
    for i in range(1, B + 1):
        answer += dp[i] * math.comb(B, i)

    print(answer)
```

---

## ⏱️ 시간 / 공간 복잡도

* **시간 복잡도**:

  * DP 계산: `O(B²)`
  * 전체 입력: `O(N × B²)`
  * (B ≤ 11 이므로 충분히 빠름)

* **공간 복잡도**:

  * `O(B)`

## ✅ 정리 포인트

* 이 문제는 **순열 문제가 아님**
* 핵심은
  **① 버튼 선택** + **② 순서 있는 분할**
* DP의 인덱스 의미(`i개의 버튼을 전부 사용`)를 정확히 잡는 것이 관건
