# 틱택토 유효성 검증기 (Tic-Tac-Toe Validator)

## 📝 문제 설명

틱택토 게임에서 가능한 모든 보드 상태를 생성하고, 입력받은 보드가 유효한 게임 결과인지 검증하는 프로그램입니다.

## 🎯 주요 기능

- DFS(깊이 우선 탐색)를 이용한 모든 가능한 게임 상태 생성
- X가 선공, O가 후공으로 번갈아 가며 진행
- 승리 조건(가로, 세로, 대각선) 판별
- 생성된 유효한 상태들과 입력을 비교하여 검증

## 💡 알고리즘

### 1. 게임 상태 생성 (DFS)

```
초기 상태: 3x3 빈 보드
↓
X 차례 (짝수 턴)
↓
O 차례 (홀수 턴)
↓
종료 조건:
- 누군가 승리 (3개 일직선)
- 보드가 꽉 참 (9턴)
```

### 2. 승리 조건 체크

- 가로 3줄 체크
- 세로 3줄 체크
- 대각선 2줄 체크 (↘, ↙)

## 📂 코드 구조

### 원본 코드

```python
boards = set()

def is_end(board, t_char):
    N, M = 3, 3
    # 가로 판별
    for i in range(N):
        if all(board[i][j] == t_char for j in range(M)):
            return True

    # 세로 판별
    for j in range(M):
        if all(board[i][j] == t_char for i in range(N)):
            return True

    # 대각선 판별
    if all(board[i][i] == t_char for i in range(N)):
        return True

    if all(board[i][2 - i] == t_char for i in range(N)):
        return True

    return False

def dfs(cnt, board):
    if is_end(board, 'O') or is_end(board, 'X'):
        l = ''

        for i in range(3):
            b = board[i]
            l += ''.join(b)
        boards.add(l)
        return

    if cnt == 9:
        l = ''

        for i in range(3):
            b = board[i]
            l += ''.join(b)
        boards.add(l)
        return

    for i in range(3):
        for j in range(3):
            if board[i][j] == '.':
                if cnt % 2 == 0:
                    board[i][j] = 'X'
                    dfs(cnt + 1, board)
                    board[i][j] = '.'
                else:
                    board[i][j] = 'O'
                    dfs(cnt + 1, board)
                    board[i][j] = '.'

dfs(0, [['.'] * 3 for _ in range(3)])

while True:
    l = input()
    if l == 'end':
        break

    if l in boards:
        print('valid')
    else:
        print('invalid')
```

## ✨ 개선된 최종 코드

```python
BOARD_SIZE = 3

def board_to_string(board):
    """보드를 문자열로 변환"""
    return ''.join(''.join(row) for row in board)

def is_end(board, target_char):
    """승리 조건 체크"""
    # 가로 체크
    for row in board:
        if all(cell == target_char for cell in row):
            return True

    # 세로 체크
    for col in range(BOARD_SIZE):
        if all(board[row][col] == target_char for row in range(BOARD_SIZE)):
            return True

    # 대각선 체크
    if all(board[i][i] == target_char for i in range(BOARD_SIZE)):
        return True

    if all(board[i][BOARD_SIZE - 1 - i] == target_char for i in range(BOARD_SIZE)):
        return True

    return False

def generate_all_valid_boards():
    """모든 유효한 보드 상태 생성"""
    valid_boards = set()

    def dfs(turn_count, board):
        # 종료 조건 체크
        if is_end(board, 'X') or is_end(board, 'O') or turn_count == 9:
            valid_boards.add(board_to_string(board))
            return

        # 다음 수 탐색
        current_player = 'X' if turn_count % 2 == 0 else 'O'

        for i in range(BOARD_SIZE):
            for j in range(BOARD_SIZE):
                if board[i][j] == '.':
                    board[i][j] = current_player
                    dfs(turn_count + 1, board)
                    board[i][j] = '.'

    dfs(0, [['.'] * BOARD_SIZE for _ in range(BOARD_SIZE)])
    return valid_boards

# 모든 유효한 보드 생성
boards = generate_all_valid_boards()

# 입력 처리
while True:
    line = input()
    if line == 'end':
        break
    print('valid' if line in boards else 'invalid')
```

## 📊 시간 복잡도

- **상태 생성**: O(9!) - 최악의 경우 모든 경우의 수 탐색
- **검증**: O(1) - Set 자료구조를 사용한 조회
