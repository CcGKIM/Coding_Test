# 🔳 갤러리 벽에 그림 걸기 — Python 풀이

이 코드는 갤러리의 지도에서 **빈 공간과 인접한 벽(X)** 을 찾아
**겹치지 않게 그림을 최대한 많이 배치**하는 그리디 방식 풀이이다.
(그림의 길이는 정사각형 두 칸이며, 가로 또는 세로 방향으로 설치 가능)
---

## 🧩 문제 요약

- 갤러리는 `N × M` 격자이며 `'X'`는 벽, `'.'`는 빈 공간이다.
- 그림은 길이 2, 즉 **벽 두 칸 연속**이어야 걸 수 있다.
- 단, 그림 주변(바로 위/아래 또는 좌/우)에 **빈 공간이 있어야 설치 가능**하다.
- 서로 겹칠 수 없다 → 동일한 칸에 중복 배치 금지.
- 목표: **최대 몇 개의 그림을 설치할 수 있는가?**

---

## 💡 핵심 아이디어

1. 모든 칸을 순회하며 **가로(X X)** 또는 **세로(X X)** 구조인지 확인한다.
2. 특정 방향으로 설치하려면:

   - 해당 벽 2칸의 **양 옆(또는 위/아래)** 에 빈 공간이 있어야 한다.

3. 이미 사용한 벽 칸은 `occupied` 집합에 기록하여 **겹침 방지**.
4. 가능한 위치마다 그림 설치 → `cnt` 증가.

---

## 🧱 코드

```python
N, M = map(int, input().split())

board = []
occupied = set()
cnt = 0

for _ in range(N):
    b = input()
    board.append(b)

def pic_garo(x, y):
    global cnt
    if 0 <= y + 1 < M and board[x][y] == 'X' and board[x][y + 1] == 'X':
        # 위쪽이 빈 공간일 때
        if (0 <= x - 1 < N and
            board[x - 1][y] == '.' and board[x - 1][y + 1] == '.' and
            (x, y, 'u') not in occupied and (x, y + 1, 'u') not in occupied):
            occupied.add((x, y, 'u'))
            occupied.add((x, y + 1, 'u'))
            cnt += 1

        # 아래쪽이 빈 공간일 때
        if (0 <= x + 1 < N and
            board[x + 1][y] == '.' and board[x + 1][y + 1] == '.' and
            (x, y, 'd') not in occupied and (x, y + 1, 'd') not in occupied):
            occupied.add((x, y, 'd'))
            occupied.add((x, y + 1, 'd'))
            cnt += 1


def pic_sero(x, y):
    global cnt
    if 0 <= x + 1 < N and board[x][y] == 'X' and board[x + 1][y] == 'X':
        # 왼쪽이 빈 공간일 때
        if (0 <= y - 1 < M and
            board[x][y - 1] == '.' and board[x + 1][y - 1] == '.' and
            (x, y, 'l') not in occupied and (x + 1, y, 'l') not in occupied):
            occupied.add((x, y, 'l'))
            occupied.add((x + 1, y, 'l'))
            cnt += 1

        # 오른쪽이 빈 공간일 때
        if (0 <= y + 1 < M and
            board[x][y + 1] == '.' and board[x + 1][y + 1] == '.' and
            (x, y, 'r') not in occupied and (x + 1, y + 1, 'r') not in occupied):
            occupied.add((x, y, 'r'))
            occupied.add((x + 1, y, 'r'))
            cnt += 1


for i in range(N):
    for j in range(M):
        pic_garo(i, j)
        pic_sero(i, j)

print(cnt)
```

---

## ⏱ 시간 복잡도

- 모든 칸을 방문: `O(N*M)`
- 각 칸에서 상수 시간 체크
  👉 **전체 복잡도: O(N\*M)**

메모리도 매우 가벼움 (`occupied` 정도만 추가 저장).
