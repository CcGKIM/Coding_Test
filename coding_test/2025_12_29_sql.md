# 🐶 동물 이름 처리하기 (CASE WHEN)

## 📌 문제 요약

`ANIMAL_INS` 테이블에서
이름(`NAME`)이 **NULL인 경우 `"No name"`으로 대체**하여 출력하라.

---

## 🧠 핵심 개념

### ❓ 왜 CASE WHEN을 써야 할까?

SQL에서는 `NULL`이:

* 문자열이 아님
* 비교 연산 불가 (`= NULL` ❌)

👉 **조건 분기**가 필요함

---

## ✅ 사용한 SQL 문법

### CASE WHEN 문법

```sql
CASE 
    WHEN 조건 THEN 값
    ELSE 값
END
```

---

## 🧩 전체 쿼리

```sql
SELECT 
    ANIMAL_TYPE,
    CASE 
        WHEN NAME IS NULL THEN 'No name'
        ELSE NAME
    END AS NAME,
    SEX_UPON_INTAKE
FROM ANIMAL_INS
ORDER BY ANIMAL_ID;
```

---

## 🔍 쿼리 해설 (한 줄씩)

```sql
SELECT ANIMAL_TYPE,
```

* 동물 종류 출력

```sql
CASE 
    WHEN NAME IS NULL THEN 'No name'
    ELSE NAME
END AS NAME,
```

* 이름이 없으면 `"No name"`
* 있으면 원래 이름 유지
* 결과 컬럼 이름을 `NAME`으로 지정

```sql
SEX_UPON_INTAKE
```

* 입소 당시 성별 정보

```sql
ORDER BY ANIMAL_ID
```

* 문제 요구사항: ID 기준 정렬

---

## 💡 더 좋은 대안 (실무 스타일)

### ✔️ IFNULL / COALESCE (더 간결함)

```sql
SELECT 
    ANIMAL_TYPE,
    IFNULL(NAME, 'No name') AS NAME,
    SEX_UPON_INTAKE
FROM ANIMAL_INS
ORDER BY ANIMAL_ID;
```

또는 (표준 SQL)

```sql
SELECT 
    ANIMAL_TYPE,
    COALESCE(NAME, 'No name') AS NAME,
    SEX_UPON_INTAKE
FROM ANIMAL_INS
ORDER BY ANIMAL_ID;
```

### 차이점 요약

| 함수          | 특징                 |
| ----------- | ------------------ |
| `CASE WHEN` | 가장 범용적, 조건 확장 쉬움   |
| `IFNULL`    | MySQL 전용, 짧고 직관적   |
| `COALESCE`  | 표준 SQL, 여러 값 처리 가능 |

---

## 🎯 언제 CASE WHEN을 쓰는 게 좋을까?

* 조건이 **여러 개**일 때
* NULL 말고도 값 범위에 따라 분기할 때
* 가독성을 강조하고 싶을 때

---

## 🔑 핵심 요약

> **NULL 처리는 비교가 아니라 조건 분기다**

이 문제는
👉 **CASE WHEN / NULL 처리 감각을 묻는 기본기 문제**
