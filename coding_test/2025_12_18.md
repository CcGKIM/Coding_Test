## 🌊 수면 이동 경우의 수 (Dynamic Programming)

### 📌 문제 개요

* 시작 시점에 수면은 **k cm**
* 총 **n초** 동안 수면이 변화
* 매 초마다 수면은 **+1cm 또는 -1cm** 이동
* 수면 높이는 **0 이하로 내려갈 수 없음**
* n초 후 **수면이 1cm 이상인 모든 경우의 수**를 구한다

---

## 💡 접근 방법

이 문제는 **시간의 흐름에 따라 상태가 변하는 문제**이므로
**DP(동적 계획법)** 이 자연스럽다.

---

## 🧠 DP 정의

```text
dp[i][j] = i초 후에 수면이 j cm인 경우의 수
```

### 초기 상태

* 시작 시점(0초)에는 수면이 k cm 하나뿐

```python
dp[0][k] = 1
```

---

## 🔄 상태 전이

수면은 매 초마다 **±1cm 이동** 가능하므로:

```text
dp[i][j] =
    dp[i-1][j-1]  (이전 초에 j-1 → +1)
  + dp[i-1][j+1]  (이전 초에 j+1 → -1)
```

단,

* 수면 높이는 **항상 1 이상**이어야 한다
* 배열 범위를 벗어나지 않도록 체크 필요

---

## 🧪 최종 결과

n초가 지난 후,

* 수면이 **1cm 이상인 모든 경우의 수의 합**

```python
answer = sum(dp[n][1:])
```

---

## 🧩 전체 코드

```python
k, n = map(int, input().split())

# dp[i][j]: i초 후에 수면이 j cm인 경우의 수
dp = [[0] * (k + n + 1) for _ in range(n + 1)]
dp[0][k] = 1

for i in range(1, n + 1):
    for j in range(1, k + n + 1):
        if j - 1 >= 1:
            dp[i][j] += dp[i - 1][j - 1]
        if j + 1 <= k + n:
            dp[i][j] += dp[i - 1][j + 1]

answer = sum(dp[n][1:])
print(answer)
```

---

## ⏱ 시간 & 공간 복잡도

* **시간 복잡도:**
  [
  O(n \times (k + n))
  ]

* **공간 복잡도:**
  [
  O(n \times (k + n))
  ]

---

## 🚀 최적화 아이디어 (선택)

현재 DP는 **이전 초 정보만 사용**하므로
공간을 줄이고 싶다면 **1차원 DP(rolling array)** 로 최적화 가능

```text
이전 dp → 현재 dp
```

👉 공간 복잡도:
[
O(k + n)
]

(이 문제에서는 가독성 측면에서 2차원 DP도 충분히 합리적)

---

## ✨ 핵심 포인트 요약

* 시간 흐름 + 상태 제한 → **DP**
* `dp[i][j] = dp[i-1][j-1] + dp[i-1][j+1]`
* 수면 높이 **0 이하 금지 조건**이 핵심
* 마지막은 조건 만족하는 상태만 합산
