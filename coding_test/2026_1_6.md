# 🧀 치즈 녹이기 시뮬레이션 (BFS)

외부 공기와 **2면 이상 접촉한 치즈가 한 시간에 동시에 녹는 과정**을 시뮬레이션하여
**모든 치즈가 녹는 데 걸리는 시간**을 계산한다.

---

## 📌 문제 핵심 아이디어

1. **외부 공기와 내부 공기를 구분**
2. 외부 공기와 **2면 이상 맞닿은 치즈만 동시에 녹음**
3. 치즈가 녹은 자리는 즉시 외부 공기로 변함
4. 위 과정을 반복하여 전체 시간을 계산

---

## 🧠 풀이 전략 요약

### 1️⃣ 외곽 패딩으로 외부 공기 처리

* 맵을 `N x M` → `(N+2) x (M+2)` 로 확장
* 가장자리는 무조건 **외부 공기(0)** 로 처리

```text
기존 맵
→
외부를 감싼 패딩 맵
```

이렇게 하면 **외부 공기 탐색이 매우 쉬워짐**

---

### 2️⃣ BFS로 외부 공기 표시 (visited)

* `(0, 0)`을 포함한 외곽에서 시작
* `board == 0` 인 곳만 BFS
* `visited == True` → 외부 공기

---

### 3️⃣ 치즈 녹이기 시뮬레이션

* 현재 남아있는 치즈 좌표들을 순회
* 상하좌우 중 **외부 공기(`visited == True`)와 접촉한 면 개수** 계산
* **2면 이상이면 녹을 후보**

> ❗ 중요:
> **같은 시간대에 녹는 치즈는 동시에 처리**

---

### 4️⃣ 녹은 치즈 → 외부 공기 확장

* 녹은 자리에서 다시 BFS
* 내부 공기가 외부 공기로 바뀌는 효과 반영

---

### 5️⃣ 더 이상 치즈가 없을 때까지 반복

---

## 🧩 전체 코드

```python
from collections import deque

N, M = map(int, input().split())

board = []
board.append([0] * (M + 2))

for _ in range(N):
    arr = list(map(int, input().split()))
    board.append([0] + arr + [0])

board.append([0] * (M + 2))

visited = [[False] * (M + 2) for _ in range(N + 2)]
air_queue = deque()
cheese_queue = deque()

dx = (-1, 1, 0, 0)
dy = (0, 0, -1, 1)

# 외부 공기 시작점 + 치즈 위치 수집
for i in range(N + 2):
    for j in range(M + 2):
        if i == 0 or i == N + 1 or j == 0 or j == M + 1:
            air_queue.append((i, j))
            visited[i][j] = True
        if board[i][j] == 1:
            cheese_queue.append((i, j))

# 외부 공기 BFS
while air_queue:
    x, y = air_queue.popleft()
    for k in range(4):
        nx, ny = x + dx[k], y + dy[k]
        if not visited[nx][ny] and board[nx][ny] == 0:
            visited[nx][ny] = True
            air_queue.append((nx, ny))

simul_time = 0

# 치즈가 남아있는 동안 반복
while cheese_queue:
    new_cheese_queue = deque()
    melt = []

    for x, y in cheese_queue:
        contact = 0
        for k in range(4):
            nx, ny = x + dx[k], y + dy[k]
            if visited[nx][ny] and board[nx][ny] == 0:
                contact += 1

        if contact >= 2:
            melt.append((x, y))
        else:
            new_cheese_queue.append((x, y))

    # 동시에 녹이기
    for x, y in melt:
        board[x][y] = 0
        visited[x][y] = True
        air_queue.append((x, y))

    # 외부 공기 확장
    while air_queue:
        x, y = air_queue.popleft()
        for k in range(4):
            nx, ny = x + dx[k], y + dy[k]
            if not visited[nx][ny] and board[nx][ny] == 0:
                visited[nx][ny] = True
                air_queue.append((nx, ny))

    simul_time += 1
    cheese_queue = new_cheese_queue

print(simul_time)
```

---

## ⏱ 시간 복잡도

* **BFS 외부 공기 탐색**: `O(NM)`
* **치즈 시뮬레이션**: 각 치즈는 최대 한 번 녹음
  ➡️ **전체 시간 복잡도: `O(NM)`**

---

## 💡 핵심 포인트 정리

* 🔹 외부 공기 판별이 핵심 → `visited` 배열
* 🔹 **동시 처리**를 위해 녹일 치즈를 임시 리스트에 저장
* 🔹 치즈가 녹으면서 **외부 공기 영역이 확장**됨
* 🔹 BFS + 시뮬레이션의 정석 문제
