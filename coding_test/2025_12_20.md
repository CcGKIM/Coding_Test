# ⚖️ 몸무게 (Two Squares Difference)

## 📌 문제 요약

정수 `G`가 주어질 때,
다음 조건을 만족하는 **현재 몸무게** `w`를 모두 구한다.

[
w^2 - x^2 = G \quad (x < w)
]

* 가능한 `w`를 오름차순으로 출력
* 존재하지 않으면 `-1` 출력

---

## 💡 수학적 관찰

식을 변형하면:

[
w^2 = x^2 + G
]

즉,

* 과거 몸무게 `x`를 하나 정하면
* `x^2 + G`가 **완전제곱수**일 경우
* 그 제곱근이 가능한 현재 몸무게 `w`

---

## 🧠 풀이 1 — 완전제곱수 탐색 (기본 풀이)

### 아이디어

* `x = 1, 2, 3, ...` 증가시키며
* `x^2 + G`가 완전제곱수인지 검사
* `(x + 1)^2 - x^2 = 2x + 1 ≤ G` 까지만 탐색

### 코드

```python
G = int(input())

value = 1
weights = []

while (value + 1) ** 2 - value ** 2 <= G:
    target = value ** 2 + G
    root = int(target ** 0.5)

    if root * root == target:
        weights.append(root)

    value += 1

if weights:
    for w in weights:
        print(w)
else:
    print(-1)
```

### ⏱ 복잡도

* 시간 복잡도: **O(G)**
* 공간 복잡도: **O(K)** (정답 개수)

---

## 🧠 풀이 2 — 투 포인터 (차이 기반 접근)

> 💡 **이 문제에서 가장 깔끔하고 재사용성 높은 풀이**

---

### 핵심 아이디어

[
w^2 - x^2 = (w - x)(w + x)
]

* `x`, `w`를 각각 포인터처럼 증가
* 두 제곱의 차이를 직접 비교
* 차이가:

  * `G`보다 작으면 → `w` 증가
  * `G`보다 크면 → `x` 증가
  * 같으면 → 정답

---

### 알고리즘 흐름

1. `x = 1`, `w = 1` 시작
2. `diff = w^2 - x^2`
3. `diff`와 `G` 비교
4. `x < w` 조건 유지
5. `x`, `w`는 단조 증가 → 중복 없음

---

### 투 포인터 코드

```python
G = int(input())

x = 1
w = 1
result = []

while x < w or (w + 1) ** 2 - w ** 2 <= G:
    diff = w * w - x * x

    if diff == G:
        result.append(w)
        x += 1
        w += 1
    elif diff < G:
        w += 1
    else:
        x += 1

if result:
    for r in result:
        print(r)
else:
    print(-1)
```

---

### ⏱ 복잡도

* 시간 복잡도: **O(G)**
* 공간 복잡도: **O(K)**

> ✔️ 제곱 계산만 사용
> ✔️ 정렬 불필요
> ✔️ 유사 문제에 그대로 사용 가능

## ✨ 정리

* 이 문제는 **두 수의 제곱 차이** 문제
* 투 포인터는
  👉 **차이가 단조 증가/감소하는 구조**에서 강력
* 이후 비슷한 문제:

  * 두 수의 합/차
  * 제곱/거리 기반 조건
  * 연속 수 범위 탐색
    에서 그대로 활용 가능
