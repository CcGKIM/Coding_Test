# 🐉 드래곤 커브 (BOJ 15685) — Python 풀이 정리

## 📌 문제 개요

드래곤 커브는 다음 규칙으로 그려지는 프랙탈 곡선이다:

* 시작점 (x, y)
* 시작 방향 d

  * 0: →
  * 1: ↑
  * 2: ←
  * 3: ↓
* 세대 g

0세대는 선분 1개,
다음 세대는 이전 세대의 **모든 점을 끝점을 기준으로 90도 시계 회전하여 이어붙이는 방식**으로 생성된다.

문제 목표는:
📍 **여러 드래곤 커브를 보드에 그린 뒤, 네 꼭짓점이 모두 칠해진 1×1 정사각형의 개수를 구하는 것**

---

# 🔧 핵심 아이디어 요약

### 1) 드래곤 커브 생성 규칙

* 각 세대는 이전 세대의 점들을 **끝점 기준 90도 회전**하여 뒤에 붙이는 방식
* 회전 공식:
  [
  (x', y') = (x_f - (y - y_f),; y_f + (x - x_f))
  ]
* 즉, (x, y)를 끝점 (x_f, y_f)을 기준으로 시계 방향 90도 회전.

---

### 2) 보드에 커브 마킹

* 전체 보드는 0~100 범위
* 커브에서 생성된 모든 좌표를 `True`로 마킹

---

### 3) 1×1 정사각형 카운트

* (i, j)를 기준으로
  (i, j), (i+1, j), (i, j+1), (i+1, j+1)
  네 점이 모두 True면 정사각형 1개

---

# 🧠 전체 코드

```python
N = int(input())

def gen_curve(x, y, d, gen):
    stack = []
    dx = (1, 0, -1, 0)
    dy = (0, -1, 0, 1)

    for curr_gen in range(gen + 1):
        if curr_gen == 0:
            stack.append((x, y))
            stack.append((x + dx[d], y + dy[d]))
        else:
            new_stack = stack[:]

            fin_x, fin_y = stack[-1]
            for i in range(-2, -1 * len(stack) -1, -1):
                curr_x, curr_y = stack[i]
                delta_x, delta_y = (curr_x - fin_x), (curr_y - fin_y)
                new_stack.append((fin_x - delta_y, fin_y + delta_x))

            stack = new_stack

    return stack

board = [[False] * (100 + 1) for _ in range(100 + 1)]

for _ in range(N):
    x, y, d, g = map(int, input().split())

    for cx, cy in gen_curve(x, y, d, g):
        if 0 <= cx <= 100 and 0 <= cy <= 100:
            board[cx][cy] = True

answer = 0
for i in range(100 + 1):
    for j in range(100 + 1):
        if all(0 <= i + dx <= 100 and 0 <= j + dy <= 100 and board[i + dx][j + dy] == True for dx, dy in [(0, 0), (0, 1), (1, 0), (1, 1)]):
            answer += 1

print(answer)
```

# 📝 핵심 풀이 해설

### ✔ 1. 0세대 생성

시작점에서 시작 방향으로 한 칸 이동해서 선분 1개로 구성.

### ✔ 2. 다음 세대 생성

예시로 stack = [P0, P1, P2, ..., Pn] 이라고 하면
끝점 Pn을 기준으로, **P(n-1) → P0 순서로 90도씩 회전**하여 뒤에 붙임.

### ✔ 3. 회전 공식

끝점 (fx, fy) 기준 시계 90도 회전:

```
x', y' = fx - (y - fy), fy + (x - fx)
```

이를 그대로 코드에 구현.

### ✔ 4. 보드 마킹

모든 (x, y)를 True로 기록.

### ✔ 5. 정사각형 카운트

(i, j) 기준 4개의 좌표가 다 True면 정사각형 1개.
