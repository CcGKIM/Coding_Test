
# 💰 동전으로 금액 만들기 - 두 가지 동적 프로그래밍 방식 비교

이 문서는 **동전으로 특정 금액을 만드는 경우의 수를 구하는 문제**를 해결하는 두 가지 동적 프로그래밍(DP) 방법을 설명합니다.

---

## 🧠 문제 설명

주어진 것:
- 여러 종류의 동전 목록
- 목표 금액

구해야 할 것:
- **중복 없이** 동전의 합으로 목표 금액을 만들 수 있는 **경우의 수**
- **동전 순서는 중요하지 않음** (예: [1,2]와 [2,1]은 같은 경우)

---

## 🧩 방식 1: 2차원 딕셔너리 기반 DP

### 🔧 아이디어

각 금액마다, 특정 동전 이하만 사용할 때 만들 수 있는 경우의 수를 딕셔너리로 저장합니다.  
이 방식은 동전 순서를 중복 없이 세는 데 유리합니다.

### ✅ 코드

```python
T = int(input())
result = []

def number(coins, target):
    dp = [{coin: 0 for coin in coins} for _ in range(target + 1)]
    for coin in coins:
        dp[0][coin] = 1
    for i in range(1, target + 1):
        for idx in range(len(coins)):
            coin1 = coins[idx]
            for j in range(idx + 1):
                coin2 = coins[j]
                if i - coin2 >= 0:
                    dp[i][coin1] += dp[i - coin2][coin2]
    return dp[-1][coins[-1]]

for _ in range(T):
    N = int(input())
    my_coins = sorted(list(map(int, input().split())))
    my_target = int(input())
    result.append(number(my_coins, my_target))

for val in result:
    print(val)
```

## ⚡ 방식 2: 1차원 배열 기반 DP (효율적)

### 🔧 아이디어

`dp[i] = i 금액을 만들 수 있는 경우의 수`로 정의하는 일반적인 방식입니다.  
동전 먼저, 금액 다음으로 순회하면 중복 없이 조합을 구할 수 있습니다.

### ✅ 코드

```python
T = int(input())
result = []

def number(coins, target):
    dp = [0] * (target + 1)
    dp[0] = 1
    for coin in coins:
        for i in range(coin, target + 1):
            dp[i] += dp[i - coin]
    return dp[target]

for _ in range(T):
    N = int(input())
    my_coins = sorted(list(map(int, input().split())))
    my_target = int(input())
    result.append(number(my_coins, my_target))

for val in result:
    print(val)
```

---

## 📊 비교 요약

| 항목 | 방식 1 (2D 딕셔너리) | 방식 2 (1D 배열) |
|------|----------------------|------------------|
| 구현 난이도 | 중간 | 쉬움 |
| 실행 속도 | 느림 | 빠름 |
| 메모리 사용 | 많음 | 적음 |
| 직관성 | 조합 구조에 충실 | 표준 방식 |

---

## 🧾 결론

- **방식 2**는 간단하고 빠르며, 대부분의 상황에 적합합니다.
- **방식 1**은 중간 과정을 디버깅하거나, 조합 구조를 세밀히 분석할 때 유용합니다.
