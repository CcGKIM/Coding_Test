# 📘 SQL 정리 — 차량 옵션 조건 필터링 & COUNT 함수 & LIKE 패턴

## ✅ 1. 문제 SQL (원본)

```sql
SELECT CAR_TYPE, COUNT(*) AS CARS
FROM CAR_RENTAL_COMPANY_CAR
WHERE OPTIONS LIKE '%통풍시트%' 
   OR OPTIONS LIKE '%열선시트%' 
   OR OPTIONS LIKE '%가죽시트%'
GROUP BY CAR_TYPE
ORDER BY CAR_TYPE;
```

---

# ✅ 2. 코드 설명 (노션용)

### 🎯 목적

`OPTIONS` 컬럼에 특정 옵션(통풍시트, 열선시트, 가죽시트)이 포함된 차량들을
차량 종류(CAR_TYPE)별로 개수(COUNT)를 집계하는 쿼리.

### 🔍 주요 포인트

* **LIKE '%키워드%'** : 부분 문자열 검색
* 여러 조건을 OR로 연결하여 옵션 중 하나라도 포함되면 선택
* **COUNT(*) AS CARS** : 차량 수 집계
* **GROUP BY** 로 CAR_TYPE 기준 집계
* **ORDER BY CAR_TYPE** : 정렬

---

# ✅ 3. OR 조건을 더 깔끔하게 쓰는 방법

OR 세 개를 줄이면 **IN 대신 사용할 수 없음**, 하지만
**REGEXP / RLIKE**를 활용해 훨씬 깔끔하게 가능함.

### ✔️ MySQL 기준 가장 깔끔한 버전

```sql
SELECT CAR_TYPE, COUNT(*) AS CARS
FROM CAR_RENTAL_COMPANY_CAR
WHERE OPTIONS REGEXP '통풍시트|열선시트|가죽시트'
GROUP BY CAR_TYPE
ORDER BY CAR_TYPE;
```

### 👉 장점

* 패턴을 한 번에 묶어서 읽기 쉽다
* 옵션이 더 늘어나도 `|`만 추가하면 됨
* 쿼리가 더 짧고 유지보수 쉬움

# 🚀 4. LIKE 사용법 정리

## ✔ 기본 구조

```sql
컬럼 LIKE '패턴'
```

## ✔ 패턴 활용

| 패턴          | 의미                   |
| ----------- | -------------------- |
| `%keyword%` | keyword가 포함되는 모든 문자열 |
| `keyword%`  | keyword로 시작          |
| `%keyword`  | keyword로 끝남          |
| `_`         | 단일 문자 wildcard       |
| `%`         | 여러 문자 wildcard       |

## 예시

```sql
OPTIONS LIKE '%시트%'
OPTIONS LIKE 'A%'
OPTIONS LIKE '_BC'
```

# 🧮 5. SQL COUNT 함수 정리

### ✔ COUNT(*)

전체 행 수
NULL 포함 여부 상관 없음

```sql
SELECT COUNT(*) FROM table;
```

### ✔ COUNT(column)

컬럼 값이 **NULL이 아닌 행만 카운트**

```sql
SELECT COUNT(price) FROM products;
```

### ✔ COUNT(DISTINCT column)

중복 제거 후 개수 계산

```sql
SELECT COUNT(DISTINCT user_id) FROM logs;
```
