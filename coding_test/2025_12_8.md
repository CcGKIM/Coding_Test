# 백준 17255번: N으로 만들기

## 문제 요약
- 숫자를 하나 선택한 후, 왼쪽이나 오른쪽에 숫자를 계속 붙여서 목표 숫자 N을 만드는 방법의 수를 구하기
- **중요**: 숫자를 적는 과정에서 나온 수가 순서대로 모두 같다면 같은 방법

## 예제
```
입력: 521
출력: 4

1 → 21 → 521
2 → 21 → 521
2 → 52 → 521
5 → 52 → 521
```

## 접근 방법

### 핵심 아이디어
1. 비트마스크로 어떤 인덱스를 사용했는지 추적
2. min_idx, max_idx로 현재 연속된 구간 관리
3. **문자열 경로를 set에 저장**하여 중복 제거

### 왜 문자열 경로를 저장해야 하는가?

처음에는 인덱스 선택 순서만 저장하면 될 것 같지만, 반례가 존재:

**"1111"의 경우:**
- 인덱스 순서 `[0,1,2,3]`: "1" → "11" → "111" → "1111"
- 인덱스 순서 `[1,0,2,3]`: "1" → "11" → "111" → "1111"

→ 인덱스 순서는 다르지만 **문자열 경로는 동일**하므로 1가지로 세어야 함

→ 따라서 문자열 경로를 tuple로 만들어 set에 저장해야 정확한 카운트 가능

## 코드

```python
N = input().strip()
length = len(N)
result_set = set()

def dfs(bit, min_idx, max_idx, curr_str, path):
    if bit == (1 << length) - 1:
        result_set.add(tuple(path))
        return
    
    if min_idx is None:  # 시작점 선택
        for i in range(length):
            dfs(1 << i, i, i, N[i], [N[i]])
    else:
        # 왼쪽 확장
        if min_idx > 0 and not (bit & (1 << (min_idx - 1))):
            new_str = N[min_idx - 1] + curr_str
            dfs(bit | (1 << (min_idx - 1)), min_idx - 1, max_idx, new_str, path + [new_str])
        
        # 오른쪽 확장
        if max_idx < length - 1 and not (bit & (1 << (max_idx + 1))):
            new_str = curr_str + N[max_idx + 1]
            dfs(bit | (1 << (max_idx + 1)), min_idx, max_idx + 1, new_str, path + [new_str])

dfs(0, None, None, '', [])
print(len(result_set))
```

## 복잡도
- **시간**: O(2^n × n) - 최악의 경우 모든 순서 탐색
- **공간**: O(결과 개수 × 경로 길이) - set에 저장되는 경로들

## 최적화 시도 및 결론
- 인덱스만 저장: ❌ 동일한 문자열 경로 중복 카운트
- (비트, min, max)만 저장: ❌ 도달 경로가 달라도 상태는 같을 수 있음
- **문자열 경로 저장**: ✅ 유일하게 정확한 방법

## 배운 점
- 경로 자체를 추적해야 하는 문제는 상태만으로는 충분하지 않음
- 메모이제이션이 항상 가능한 것은 아님 (경로 의존적인 경우)
- 문제의 "같은 방법"의 정의를 정확히 이해하는 것이 중요
