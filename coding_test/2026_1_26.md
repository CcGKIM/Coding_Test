# ✅ 0-1 BFS로 최소 위험 비용 경로 찾기 (Grid 0~500)

## 문제 요약

* 좌표 평면을 `0 ≤ x, y ≤ 500` 격자로 본다.
* 시작점 `(0,0)`에서 도착점 `(500,500)`까지 이동한다.
* 이동은 상/하/좌/우 4방향.
* 특정 직사각형 영역들은:

  * **죽음(Death) 구역**: 들어가면 즉시 불가능(통과 불가)
  * **위험(Danger) 구역**: 들어가면 비용 `+1`
  * 그 외: 비용 `+0`
* 목표: **누적 위험 비용의 최솟값** 구하기
  (도달 불가면 `-1`)

---

## 핵심 아이디어

이 문제는 간선 가중치가 **0 또는 1**만 존재하는 최단거리 문제다.

* 안전 칸으로 이동: 비용 0
* 위험 칸으로 이동: 비용 1
* 죽음 칸: 이동 불가

✅ 그래서 **다익스트라 대신 0-1 BFS**를 쓰면 빠르고 구현도 깔끔해진다.

### 0-1 BFS 동작 방식

* 비용이 **0**인 이동은 `deque`의 **앞쪽(appendleft)** 에 넣는다.
* 비용이 **1**인 이동은 `deque`의 **뒤쪽(append)** 에 넣는다.
* 이렇게 하면 “현재까지 비용이 작은 상태”부터 자연스럽게 먼저 처리되어 최단거리를 보장한다.

---

## 구현 포인트

### 1) 칸의 비용 판정: `get_cost(x, y)`

* 먼저 **죽음 구역인지 확인** → 맞으면 `-1` (막힘)
* 아니면 **위험 구역인지 확인** → 맞으면 `1`
* 둘 다 아니면 `0`

> ⚠️ 죽음이 위험보다 우선이다.
> (죽음 구역이면 위험 여부와 관계없이 무조건 통과 불가)

### 2) 최단거리 배열 `dist[501][501]`

* `dist[x][y]` = (0,0)에서 (x,y)까지의 최소 위험 비용
* 초기값은 `INF`, 시작점은 `0`

### 3) BFS 진행

* `(x,y)`에서 4방향 `(nx,ny)`로 이동
* `c = get_cost(nx, ny)`
* `c != -1`이면 이동 가능
* 더 좋은 비용이면 갱신하고:

  * `c == 0` → `appendleft`
  * `c == 1` → `append`

---

## 시간/공간 복잡도

* 격자 크기: `501 * 501 ≈ 251,001` 정점
* 0-1 BFS 자체: **O(V + E)**
  여기서 `E ≈ 4V`라서 사실상 `O(V)`급

✅ 다만 현재 구현의 병목은 `get_cost()`가 매 이동마다 **직사각형 리스트를 전부 순회**한다는 점.

* `get_cost()` : `O(N + M)`
* 전체 탐색: 대략 `O(V * (N+M))`
  → 직사각형이 많으면 느려질 수 있음

공간: `dist`가 `501*501` → **O(501²)**

---

## 개선 포인트 (중요)

현재처럼 매 칸마다 직사각형을 훑기보다, **미리 보드를 칠해두면** 훨씬 빨라진다.

### ✅ 개선 방법: 위험/죽음 영역을 501×501 보드에 미리 표시

1. `board[x][y] = -1 / 1 / 0` 형태로 저장

   * 죽음: -1
   * 위험: 1
   * 안전: 0
2. BFS 중에는 `board[nx][ny]`만 보면 끝 → `O(1)`

미리 칠하기 비용은:

* 각 직사각형을 `(x1..x2, y1..y2)`로 루프 돌며 채우면
* 최악 `501²` 범위라서 충분히 감당 가능(상수도 작음)

---

## 자주 하는 실수 체크

* `if d > dist[x][y]` 라인은 사실상 의미가 없음
  (`d = dist[x][y]`로 받았기 때문)

  * 보통은 우선순위 큐에서 쓰는 패턴이라 deque에서는 제거해도 됨
