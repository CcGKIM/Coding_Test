# 🐾 동물 보호소 입소 기록 날짜 포맷 변경

## 📌 문제 개요

* `ANIMAL_INS` 테이블에서

  * 동물의 ID
  * 이름
  * 입소 날짜
* 를 조회한다.
* 단, **날짜는 `YYYY-MM-DD` 형식으로 출력**해야 한다.
* 결과는 **ANIMAL_ID 오름차순 정렬**한다.

---

## 🧩 사용 테이블

### `ANIMAL_INS`

| 컬럼명         | 설명        |
| ----------- | --------- |
| `ANIMAL_ID` | 동물 ID     |
| `NAME`      | 동물 이름     |
| `DATETIME`  | 보호소 입소 일시 |

---

## 🧑‍💻 SQL 쿼리

```sql
SELECT 
    ANIMAL_ID, 
    NAME, 
    DATE_FORMAT(DATETIME, '%Y-%m-%d') AS 날짜
FROM ANIMAL_INS
ORDER BY ANIMAL_ID;
```

---

## 🧠 핵심 포인트 설명

### 1️⃣ `DATE_FORMAT()`

```sql
DATE_FORMAT(DATETIME, '%Y-%m-%d')
```

* `DATETIME` 타입을 **문자열 형태의 날짜 포맷**으로 변환
* `%Y` : 연도 (4자리)
* `%m` : 월 (2자리)
* `%d` : 일 (2자리)

📌 **MySQL 전용 함수**라는 점이 중요

---

### 2️⃣ 컬럼 별칭(Alias)

```sql
AS 날짜
```

* 출력 컬럼명을 한글로 지정
* 문제 요구사항 충족
* 가독성 ↑

---

### 3️⃣ 정렬 기준

```sql
ORDER BY ANIMAL_ID
```

* 기본값은 `ASC`
* 문제 조건을 정확히 반영

---

## ⚠️ 자주 하는 실수

### ❌ 잘못된 예시 (DB 혼동)

```sql

```

👉 **MySQL에서는 사용 불가**

---

### ❌ ORDER BY 누락

```sql
-- 정렬 안 하면 채점 실패 가능
```

---

## 🔄 DB별 날짜 포맷 비교

| DB         | 날짜 포맷 함수                        |
| ---------- | ------------------------------- |
| MySQL      | `DATE_FORMAT(date, '%Y-%m-%d')` |
| Oracle     | `TO_CHAR(date, 'YYYY-MM-DD')`   |
| PostgreSQL | `TO_CHAR(date, 'YYYY-MM-DD')`   |

---

## ✨ 한 줄 요약

> **MySQL에서는 날짜 출력 형식이 필요하면 `DATE_FORMAT()`을 사용한다.**
