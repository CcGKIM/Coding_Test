# 🍽️ SQL: 음식 종류별 가장 인기 많은 음식점 찾기

이 쿼리는 `REST_INFO` 테이블에서 **각 FOOD_TYPE(음식 종류)** 에 대해
**FAVORITES(즐겨찾기 수)가 가장 많은 음식점**을 조회하는 코드이다.

---

## 📌 사용된 SQL 코드

```sql
SELECT 
    a.FOOD_TYPE, 
    a.REST_ID, 
    a.REST_NAME, 
    a.FAVORITES
FROM (
    SELECT 
        FOOD_TYPE, 
        REST_ID, 
        REST_NAME, 
        FAVORITES,
        MAX(FAVORITES) OVER (PARTITION BY FOOD_TYPE) AS MAX_FAV
    FROM REST_INFO
) a
WHERE a.FAVORITES = a.MAX_FAV
ORDER BY a.FOOD_TYPE DESC;
```

---

# 📘 설명

## 1. WINDOW FUNCTION 사용

```sql
MAX(FAVORITES) OVER (PARTITION BY FOOD_TYPE)
```

* FOOD_TYPE(음식 종류)별로 FAVORITES의 **최댓값**을 구한다.
* GROUP BY와 달리 **행 단위로 MAX 값을 그대로 붙여준다**.

예시로

```
FOOD_TYPE = 'Korean'
FAVORITES 값 = 10, 15, 15, 8
```

→ 모든 Korean 행에 `MAX_FAV = 15` 가 붙음

---

## 2. 가장 인기 많은 음식점만 필터링

```sql
WHERE a.FAVORITES = a.MAX_FAV
```

* FAVORITES가 해당 FOOD_TYPE의 최댓값과 같은 행만 선택
* 즉, **음식 종류별 "가장 인기 있는" 음식점만 추출**

동률인 경우 여러 개가 나올 수 있음.

---

## 3. 음식 종류별 결과 정렬

```sql
ORDER BY a.FOOD_TYPE DESC
```

* 음식 종류를 기준으로 내림차순 정렬한다.

# 🚀 장점 및 최적화 포인트

### ✔ GROUP BY보다 유연함

* 단순히 MAX만 조회하는 것이 아니라
* **해당 레코드의 모든 값을 유지한 채 비교 가능**

### ✔ 동순위(공동 1위)도 자동 처리

### ✔ 서브쿼리를 CTE로 변경 가능 (가독성 UP)

```sql
WITH ranked AS (
    SELECT 
        FOOD_TYPE,
        REST_ID,
        REST_NAME,
        FAVORITES,
        MAX(FAVORITES) OVER(PARTITION BY FOOD_TYPE) AS MAX_FAV
    FROM REST_INFO
)
SELECT FOOD_TYPE, REST_ID, REST_NAME, FAVORITES
FROM ranked
WHERE FAVORITES = MAX_FAV
ORDER BY FOOD_TYPE DESC;
```

# 📌 GitHub README용 핵심 요약

* SQL 윈도우 함수 `MAX() OVER()`로 음식 종류별 즐겨찾기 최댓값 계산
* 최댓값과 같은 레코드만 WHERE로 필터링
* 공동 1위도 자동 포함
* GROUP BY보다 유지 정보가 많아 분석에 유리
