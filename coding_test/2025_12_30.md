---

## 1️⃣ 문제 핵심 구조 (한 줄 요약)

* **시간 N** 안에서
* **K개의 과목 중 일부를 선택**해서
* **중요도 합을 최대화**
* 각 과목은 **한 번만 선택 가능 (0/1)**

👉 즉, **0/1 Knapsack 문제**

---

## 2️⃣ dp 정의 다시 보기 (아주 중요)

```python
dp[i][t]
```

의미:

> **앞에서 i번째 과목까지 고려했을 때,
> 총 공부 시간이 t일 때 얻을 수 있는 최대 중요도**

이 정의가 명확해서 코드가 깔끔해진 거야.

---

## 3️⃣ 현재 코드 한 줄씩 쉽게 설명

### 입력 처리

```python
arr.append((i, t))  # (중요도, 시간)
```

---

### DP 테이블

```python
dp = [[0] * (N + 1) for _ in range(K + 1)]
```

* 행: 과목 개수 (0 ~ K)
* 열: 사용한 시간 (0 ~ N)

---

### 점화식 부분 ⭐

```python
for i in range(1, K + 1):
    for t in range(1, N + 1):
        curr_i, curr_t = arr[i - 1]
```

#### ① 이번 과목을 **선택하는 경우**

```python
if t - curr_t >= 0:
    dp[i][t] = max(dp[i][t], dp[i - 1][t - curr_t] + curr_i)
```

의미:

> 이전 과목까지 `t - curr_t` 시간 썼고
> 이번 과목을 추가로 선택하면
> 중요도 `curr_i`만큼 증가

---

#### ② 이번 과목을 **선택하지 않는 경우**

```python
dp[i][t] = max(dp[i][t], dp[i - 1][t])
```

---

### 최종 답

```python
print(dp[K][N])
```

👉 모든 과목을 고려했을 때, 시간 N 안에서 최대 중요도

---

## 4️⃣ 시간 & 공간 복잡도

* **시간 복잡도**:
  [
  O(K \times N)
  ]

* **공간 복잡도**:
  [
  O(K \times N)
  ]

👉 K, N이 둘 다 10⁴ 이상이면 메모리 터질 수 있음

---

## 5️⃣ 💥 핵심 최적화: 1차원 DP로 줄이기

### 왜 가능할까?

`dp[i]`는 **오직 dp[i-1]만 참조**함
→ 행 하나만 유지해도 됨

---

### ⚠️ 주의 포인트 (중요!)

* **시간 t는 반드시 뒤에서 앞으로 순회**
* 그래야 같은 과목을 중복 선택하지 않음

---

### ✅ 최적화 코드 (실전용)

```python
N, K = map(int, input().split())

arr = []
for _ in range(K):
    i, t = map(int, input().split())
    arr.append((i, t))

dp = [0] * (N + 1)

for curr_i, curr_t in arr:
    for t in range(N, curr_t - 1, -1):
        dp[t] = max(dp[t], dp[t - curr_t] + curr_i)

print(dp[N])
```

### 📉 공간 복잡도 개선

* **O(K × N) → O(N)**

👉 코테에서는 이게 거의 정답 템플릿이야

## 6️⃣ 다른 관점 풀이 (비효율적이지만 알아두면 좋은)

### 🔹 DFS + 백트래킹 (비추천)

```python
def dfs(idx, time, score):
    if time > N:
        return
    if idx == K:
        ans = max(ans, score)
        return

    dfs(idx + 1, time, score)
    dfs(idx + 1, time + arr[idx][1], score + arr[idx][0])
```

* 시간 복잡도: **O(2^K)**
* K ≤ 20 정도일 때만 가능
* 👉 **DP 필요성을 깨닫게 해주는 풀이**

---

## 7️⃣ 이 문제에서 꼭 기억해야 할 포인트

✅ 이 문제는 **무조건 Knapsack**
✅ “시간 제한 + 가치 최대” → 99% 배낭
✅ 2차원 DP → 1차원 DP로 줄일 수 있는지 항상 생각
✅ **뒤에서 앞으로 순회**는 0/1 배낭의 생명줄
