# 백준 22943번 - 수

## 문제 링크
https://www.acmicpc.net/problem/22943

## 문제 요약
0부터 9까지 K가지의 숫자를 한 번씩만 사용하여 만들 수 있는 수 중, 아래 두 조건을 모두 만족하는 수의 개수를 구하는 문제

**조건:**
1. 서로 다른 두 개의 소수의 합으로 나타낼 수 있는 경우
2. M으로 나누어떨어지지 않을 때까지 나눈 수가 두 개의 소수의 곱인 경우

## 알고리즘 분류
- 백트래킹
- 에라토스테네스의 체
- 브루트포스

## 풀이 설명

### 핵심 아이디어
1. **에라토스테네스의 체**로 K자리 수 범위의 모든 소수를 미리 생성
2. **백트래킹**으로 K자리 순열(0~9 중 K개 선택, 중복X) 생성
3. 생성된 각 수가 두 조건을 만족하는지 검증

### 구현 포인트

#### 1. 소수 생성 (에라토스테네스의 체)
```python
is_odd = [True] * (int(str(9) * K) + 1)
for i in range(2, int(str(9) * K) + 1):
    if is_odd[i]:
        odd_set.add(i)
        for j in range(i + i, int(str(9) * K) + 1, i):
            is_odd[j] = False
```
- `str(9) * K`: K=3이면 "999" → 999까지의 소수 생성

#### 2. 조건 1 검증 - 서로 다른 두 소수의 합
```python
def is_valid_one(number):
    for v1 in odd_set:
        if number - v1 != v1 and number - v1 in odd_set:
            return True
    return False
```
- 모든 소수 v1에 대해 `number - v1`이 소수인지 확인
- `number - v1 != v1`: 서로 다른 소수여야 함

#### 3. 조건 2 검증 - M으로 나눈 후 두 소수의 곱
```python
def is_valid_two(number):
    while number > 0 and number % M == 0:
        number = number // M  # M으로 나누어떨어지지 않을 때까지 나누기
    
    for v1 in odd_set:
        if number % v1 == 0 and number // v1 in odd_set:
            return True
    return False
```
- M으로 최대한 나눈 후, 남은 수가 두 소수의 곱인지 확인
- `number // v1`도 소수여야 함 (같은 소수 허용)

#### 4. 백트래킹으로 순열 생성
```python
def backtrack(cnt, number):
    if cnt == K:
        if is_valid_one(''.join(number)) and is_valid_two(''.join(number)):
            answer += 1
        return
    
    # 첫 자리: 1~9, 나머지: 0~9
    start = 1 if cnt == 0 else 0
    for i in range(start, 10):
        if not used[i]:
            used[i] = True
            number.append(str(i))
            backtrack(cnt + 1, number)
            number.pop()
            used[i] = False
```
- 맨 앞자리는 0이 올 수 없으므로 1~9
- `used` 배열로 중복 방지

## 시간 복잡도
- 소수 생성: O(N log log N), N = 10^K
- 백트래킹: O(10! / (10-K)!) ≈ O(30,240) (K=5 최대)
- 각 수마다 조건 검증: O(P), P = 소수 개수
- **전체: O(N log log N + 30,240 × P)**

## 코드
```python
K, M = map(int, input().split())

# 에라토스테네스의 체로 소수 생성
is_odd = [True] * (int(str(9) * K) + 1)
odd_set = set()

for i in range(2, int(str(9) * K) + 1):
    if is_odd[i]:
        odd_set.add(i)
        for j in range(i + i, int(str(9) * K) + 1, i):
            is_odd[j] = False

used = [False] * 10

def is_valid_one(number):
    """서로 다른 두 소수의 합인지 확인"""
    number = int(number)
    for v1 in odd_set:
        if number - v1 != v1 and number - v1 in odd_set:
            return True
    return False

def is_valid_two(number):
    """M으로 나눈 후 두 소수의 곱인지 확인"""
    number = int(number)
    while number > 0 and number % M == 0:
        number = number // M
    
    for v1 in odd_set:
        if number % v1 == 0 and number // v1 in odd_set:
            return True
    return False

answer = 0

def backtrack(cnt, number):
    global answer
    if cnt == K:
        if is_valid_one(''.join(number)) and is_valid_two(''.join(number)):
            answer += 1
        return
    
    if K == 1:
        for i in range(1, 10):
            if not used[i]:
                used[i] = True
                number.append(str(i))
                backtrack(cnt + 1, number)
                used[i] = False
                number.pop()
    else:
        if cnt == 0:
            for i in range(1, 10):
                if not used[i]:
                    used[i] = True
                    number.append(str(i))
                    backtrack(cnt + 1, number)
                    used[i] = False
                    number.pop()
        else:
            for i in range(10):
                if not used[i]:
                    used[i] = True
                    number.append(str(i))
                    backtrack(cnt + 1, number)
                    used[i] = False
                    number.pop()

backtrack(0, [])
print(answer)
```
