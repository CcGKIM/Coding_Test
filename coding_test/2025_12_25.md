# 🧱 미로에서 최소 벽 부수기 (0-1 BFS)

## 📌 문제 요약

* `N x M` 크기의 미로가 주어진다.
* `0`은 빈 방, `1`은 벽이다.
* `(0,0)`에서 `(N-1, M-1)`까지 이동할 때
  **부숴야 하는 벽의 최소 개수**를 구하라.
* 상하좌우로만 이동 가능하다.

---

## 💡 핵심 아이디어

이 문제는 **최단 거리 문제**지만,
이동 비용이 두 종류뿐이다.

| 이동       | 비용 |
| -------- | -- |
| 빈 방(`0`) | 0  |
| 벽(`1`)   | 1  |

👉 이런 구조에서는 **다익스트라 대신 0-1 BFS**가 최적이다.

---

## 🧠 왜 0-1 BFS인가?

* 일반 BFS ❌ → 비용 개념 없음
* 다익스트라 ⭕ → 가능하지만 느림 (`O(E log V)`)
* **0-1 BFS ⭕⭕**

  * 간선 비용이 `0` 또는 `1`일 때 최적
  * `deque` 사용
  * 시간복잡도 `O(V + E)`

---

## 🧩 접근 방법

1. `visited[x][y]`
   → `(x,y)`까지 오면서 **부순 벽의 최소 개수**
2. 시작점 `(0,0)`에서 BFS 시작
3. 이동할 때

   * 빈 방이면 비용 증가 ❌
   * 벽이면 비용 +1
4. **더 적은 비용으로 도달 가능할 때만 갱신**

---

## 🧑‍💻 Python 코드 (0-1 BFS)

```python
from collections import deque

M, N = map(int, input().split())

board = []
visited = [[float('inf')] * M for _ in range(N)]

for _ in range(N):
    board.append(list(map(int, input())))

dx = (-1, 1, 0, 0)
dy = (0, 0, -1, 1)

queue = deque()
queue.append((0, 0))
visited[0][0] = 0

while queue:
    x, y = queue.popleft()

    for k in range(4):
        nx, ny = x + dx[k], y + dy[k]

        if 0 <= nx < N and 0 <= ny < M:
            cost = visited[x][y] + board[nx][ny]

            if cost < visited[nx][ny]:
                visited[nx][ny] = cost

                # 0-1 BFS 핵심
                if board[nx][ny] == 0:
                    queue.appendleft((nx, ny))
                else:
                    queue.append((nx, ny))

print(visited[N - 1][M - 1])
```

---

## ⏱ 시간 & 공간 복잡도

| 항목 | 복잡도        |
| -- | ---------- |
| 시간 | `O(N × M)` |
| 공간 | `O(N × M)` |

---

## 🔍 포인트 정리

* `visited`는 **방문 여부가 아니라 최소 비용**
* 벽 여부(`0/1`)가 곧 간선 비용
* `deque.appendleft()` / `append()`가 핵심
* 다익스트라보다 빠르고 구현도 간결

---

## ✨ 확장 아이디어

* 벽 비용이 2 이상 → 다익스트라 필요
* 벽을 **K개까지만 부술 수 있는 경우** → 상태에 `k` 추가
* 최단 경로 복원 → parent 배열 추가
