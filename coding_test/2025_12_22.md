# 백준 1473 - 종이 접기

## 문제 링크
https://www.acmicpc.net/problem/1473

## 문제 설명
원룡이가 임의로 접었다 핀 종이가 주어질 때, 이 종이를 동호의 규칙대로 다시 접을 수 있는지 판별하는 문제.

### 동호의 접기 규칙
- 항상 종이를 **반으로만** 접음
- 오른쪽 반을 반시계 방향으로 접어서 왼쪽 위로 (IN, 0)
- 오른쪽 반을 시계 방향으로 접어서 왼쪽 아래로 (OUT, 1)

### 입력
- 첫째 줄: 테스트 케이스 개수 T
- 둘째 줄부터: 접힌 종이의 패턴 (0: IN, 1: OUT)
- 문자열 길이는 항상 2^N - 1 형태

### 출력
- 각 테스트 케이스마다 YES 또는 NO

## 핵심 아이디어

### 1. 물리적 접기 조건
종이를 중앙에서 반으로 접을 때:
- 왼쪽과 오른쪽의 **대칭 위치**가 겹침
- 같은 방향의 접힌 자국이 만나면 → **접을 수 없음** (물리적 충돌)
- 반대 방향의 접힌 자국이 만나면 → **접을 수 있음** (상쇄)

```
예: "000"
왼쪽 끝: IN(0) ↓
              ↓ 겹침
오른쪽 끝: IN(0) ↓
→ 같은 방향이라 평평하게 접을 수 없음!
```

```
예: "1000110"
왼쪽 끝: OUT(1) ↓
                ↓ 겹침
오른쪽 끝: IN(0) ↓
→ 반대 방향이라 상쇄되어 접을 수 있음!
```

### 2. 재귀 구조
- 한 번 접은 후, 두꺼워진 종이를 **또 반으로 접어야** 함
- 따라서 왼쪽 부분과 오른쪽 부분도 재귀적으로 접을 수 있어야 함

### 3. 대칭 위치 계산
중앙(mid)을 기준으로 반으로 접으면:
```
i=start:   s[start] ↔ s[end]
i=start+1: s[start+1] ↔ s[end-1]
...
i:         s[i] ↔ s[end - i + start]
```

## 코드

```python
T = int(input())

def check(start, end, s):
    # Base case: 접힌 자국이 1개면 항상 접을 수 있음
    if start == end:
        return True
    
    mid = (start + end) // 2
    
    # 대칭 위치의 값이 같으면 접을 수 없음
    for i in range(start, mid):
        if s[i] == s[end - i + start]:
            return False
    
    # 왼쪽과 오른쪽을 재귀적으로 확인
    return check(start, mid - 1, s) and check(mid + 1, end, s)

for _ in range(T):
    letter = input().strip()
    if check(0, len(letter) - 1, letter):
        print('YES')
    else:
        print('NO')
```

## 시간 복잡도
- 각 재귀 단계에서 O(N/2) 비교
- 재귀 깊이: O(log N)
- **총 시간 복잡도: O(N)**

## 예제 분석

### 예제 1: "0"
```
start=0, end=0
→ Base case, return True
→ YES
```

### 예제 2: "000"
```
start=0, end=2, mid=1
i=0: s[0]='0' vs s[2]='0' → 같음!
→ return False
→ NO
```

### 예제 3: "1000110"
```
start=0, end=6, mid=3

1차 검사:
i=0: s[0]='1' vs s[6]='0' → 다름 ✓
i=1: s[1]='0' vs s[5]='1' → 다름 ✓
i=2: s[2]='0' vs s[4]='1' → 다름 ✓

재귀:
check(0, 2, "100"):
  mid=1
  i=0: s[0]='1' vs s[2]='0' → 다름 ✓
  check(0, 0) → True
  check(2, 2) → True
  → True

check(4, 6, "110"):
  mid=5
  i=4: s[4]='1' vs s[6]='0' → 다름 ✓
  check(4, 4) → True
  check(6, 6) → True
  → True

→ YES
```

## 핵심 포인트
1. **대칭 위치의 값이 반대여야** 접을 수 있음 (물리적 상쇄)
2. **재귀적으로 모든 부분**이 접을 수 있어야 함
3. `s[i] == s[end - i + start]`면 **False** 반환
