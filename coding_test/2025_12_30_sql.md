## 📌 문제 핵심 요약

* **ANIMAL_INS** 테이블에서
* 동물의 **중성화 여부를 판별**해서
* `O / X`로 표시
* **ANIMAL_ID 기준 오름차순 정렬**

---

## ✅ 최종 SQL 코드

```sql
SELECT 
    ANIMAL_ID, 
    NAME, 
    CASE 
        WHEN SEX_UPON_INTAKE LIKE '%Neutered%' THEN 'O'
        WHEN SEX_UPON_INTAKE LIKE '%Spayed%' THEN 'O'
        ELSE 'X' 
    END AS '중성화'
FROM ANIMAL_INS
ORDER BY ANIMAL_ID;
```

---

## 🧠 한 줄씩 쉽게 설명

### 1️⃣ SELECT 컬럼

```sql
SELECT ANIMAL_ID, NAME,
```

* 동물 ID
* 이름

---

### 2️⃣ CASE WHEN 핵심 로직 ⭐

```sql
CASE 
    WHEN SEX_UPON_INTAKE LIKE '%Neutered%' THEN 'O'
    WHEN SEX_UPON_INTAKE LIKE '%Spayed%' THEN 'O'
    ELSE 'X'
END AS '중성화'
```

#### 의미 해석

* `SEX_UPON_INTAKE` 컬럼에

  * **Neutered** (수컷 중성화)
  * **Spayed** (암컷 중성화)
    가 포함되어 있으면 👉 **중성화 O**
* 그 외는 👉 **중성화 X**

👉 문자열이 `"Neutered Male"`, `"Spayed Female"` 처럼 들어오기 때문에
**LIKE + %패턴** 사용이 정확함

---

### 3️⃣ 정렬

```sql
ORDER BY ANIMAL_ID;
```

* 문제 조건에 맞게 **ANIMAL_ID 오름차순**

---

## 🧩 왜 LIKE를 써야 할까?

❌ 이렇게 하면 안 됨:

```sql
SEX_UPON_INTAKE = 'Neutered'
```

✔️ 실제 데이터 예:

* `Neutered Male`
* `Spayed Female`
* `Intact Male`

👉 **부분 문자열 판별**이 필요하므로 `LIKE '%문자%'`

---

## ✨ 조금 더 깔끔한 개선 버전 (선택)

### ✔️ OR로 묶기 (가독성 ↑)

```sql
SELECT 
    ANIMAL_ID,
    NAME,
    CASE 
        WHEN SEX_UPON_INTAKE LIKE '%Neutered%' 
          OR SEX_UPON_INTAKE LIKE '%Spayed%' 
        THEN 'O'
        ELSE 'X'
    END AS '중성화'
FROM ANIMAL_INS
ORDER BY ANIMAL_ID;
```

## 📝 GitHub README용 정리 문구 (복붙용)

> `CASE WHEN`과 `LIKE`를 활용해
> 동물의 성별 정보 문자열에
> **Neutered / Spayed 포함 여부**를 판별하여
> 중성화 여부를 `O / X`로 출력한다.
