# 🏆 백준 1726 - 로봇

## 📌 문제 설명
로봇이 주어진 격자 맵에서 목표 위치로 이동해야 합니다.  
이동은 **1~3칸 직진**할 수 있으며, **왼쪽 또는 오른쪽으로 방향을 회전**할 수 있습니다.  
최소한의 이동으로 목표 위치와 방향을 맞추는 것이 목표입니다.

- **맵 크기**: `N x M` (1 ≤ N, M ≤ 100)
- **이동 방식**
  - 1~3칸 직진 가능 (벽을 만나면 멈춤)
  - 왼쪽 (`-90도`), 오른쪽 (`+90도`) 회전 가능
- **목표**: 최소한의 이동 횟수로 도착 위치 및 방향 맞추기

## 🔥 해결 방법 (BFS)
1. **BFS를 사용한 최단 거리 탐색**
   - `queue = deque((x, y, direction, cost))` 형태로 탐색
   - `cost_table[direction][x][y]` 배열을 사용하여 방문 여부 체크
2. **이동 가능 여부 체크 (`1~3칸 직진`)**
   - 벽(`1`)을 만나기 전까지 1~3칸 이동 가능
   - 이동 시 최소 거리(`cost + 1`)를 유지하는 BFS 탐색
3. **방향 전환 처리 (`왼쪽, 오른쪽 회전`)**
   - 왼쪽 회전: `direction - 1 (mod 4)`
   - 오른쪽 회전: `direction + 1 (mod 4)`
   - 회전 시 `cost + 1` 추가

## 🚀 코드 설명
```python
import sys
from collections import deque

N, M = map(int, sys.stdin.readline().split())
matrix = [list(map(int, sys.stdin.readline().split())) for _ in range(N)]

start = list(map(int, sys.stdin.readline().split()))
end = list(map(int, sys.stdin.readline().split()))

start, init_direction = (start[0] - 1, start[1] - 1), start[2]
end, end_direction = (end[0] - 1, end[1] - 1), end[2]

direction_dict = {4: 0, 1: 1, 3: 2, 2: 3}  # 방향 재정의
init_direction = direction_dict[init_direction]
end_direction = direction_dict[end_direction]

# BFS 탐색을 위한 cost 테이블 (방향 4개 × N × M)
cost_table = [[[float('inf')] * M for _ in range(N)] for _ in range(4)]

# 방향 (북, 동, 남, 서)
dx = (-1, 0, 1, 0)
dy = (0, 1, 0, -1)

def bfs(start, end, init_d):
    queue = deque([(start[0], start[1], init_d, 0)])  # (x, y, 방향, 비용)
    cost_table[init_d][start[0]][start[1]] = 0

    while queue:
        x, y, direction, cost = queue.popleft()

        # 도착점 및 방향이 맞을 경우 종료
        if (x, y, direction) == (end[0], end[1], end_direction):
            return cost

        # 1~3칸 직진
        for k in range(1, 4):
            nx, ny = x + k * dx[direction], y + k * dy[direction]
            if not (0 <= nx < N and 0 <= ny < M) or matrix[nx][ny] == 1:
                break  # 벽을 만나면 더 이상 진행 불가

            if cost + 1 < cost_table[direction][nx][ny]:  # 최단 비용 갱신
                cost_table[direction][nx][ny] = cost + 1
                queue.append((nx, ny, direction, cost + 1))

        # 왼쪽 회전
        left_d = (direction - 1) % 4
        if cost + 1 < cost_table[left_d][x][y]:
            cost_table[left_d][x][y] = cost + 1
            queue.append((x, y, left_d, cost + 1))

        # 오른쪽 회전
        right_d = (direction + 1) % 4
        if cost + 1 < cost_table[right_d][x][y]:
            cost_table[right_d][x][y] = cost + 1
            queue.append((x, y, right_d, cost + 1))

    return -1  # 목표 지점에 도달할 수 없는 경우

print(bfs(start, end, init_direction))
