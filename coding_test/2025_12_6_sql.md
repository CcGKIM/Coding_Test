# 📘 **[SQL 문제 풀이] 2022년 5월 진료과별 예약 환자 수 조회**

## 📌 **문제 설명**

다음은 종합병원의 진료 예약 정보가 담긴 `APPOINTMENT` 테이블이다.

| Column        | Type        | Description |
| ------------- | ----------- | ----------- |
| APNT_YMD      | TIMESTAMP   | 진료예약일시      |
| APNT_NO       | NUMBER(5)   | 예약번호        |
| PT_NO         | VARCHAR(10) | 환자번호        |
| MCDP_CD       | VARCHAR(6)  | 진료과 코드      |
| MDDR_ID       | VARCHAR(10) | 의사 ID       |
| APNT_CNCL_YN  | VARCHAR(1)  | 예약취소여부      |
| APNT_CNCL_YMD | DATE        | 예약취소일       |

**문제:**
2022년 5월에 *예약한 환자 수*를 **진료과 코드별로 조회**하시오.

* 컬럼명: `진료과코드`, `5월예약건수`
* 환자 수 기준 오름차순 정렬
* 환자 수가 같다면 진료과 코드 오름차순 정렬

---

## 🧠 **핵심 포인트 정리**

### 1) **환자 수 ≠ 예약 건수**

* 동일 환자가 여러 번 예약해도
  → **한 번만 카운트해야 함**
* 따라서 `COUNT(DISTINCT PT_NO)` 를 사용해야 함.

---

### 2) **문제에서 ‘취소 제외’ 조건을 명시하지 않음**

프로그래머스 SQL 문제는
**문장에 명시된 조건만 사용**하는 것이 원칙.

* 취소 여부 조건 없음 → 모든 예약 기록을 사용

---

### 3) **MySQL에서는 날짜 필터링을 YEAR(), MONTH()로 처리 가능**

```sql
YEAR(APNT_YMD) = 2022
MONTH(APNT_YMD) = 5
```

---

## ✅ **정답 SQL**

```sql
SELECT 
    MCDP_CD AS `진료과코드`,
    COUNT(DISTINCT PT_NO) AS `5월예약건수`
FROM APPOINTMENT
WHERE YEAR(APNT_YMD) = 2022
  AND MONTH(APNT_YMD) = 5
GROUP BY MCDP_CD
ORDER BY COUNT(DISTINCT PT_NO), MCDP_CD ASC;
```

---

## 📚 **해설**

### ✔ `COUNT(DISTINCT PT_NO)`

* 환자 번호 중복 제거 → 실제 환자 수 계산

### ✔ `GROUP BY MCDP_CD`

* 진료과별 집계

### ✔ `ORDER BY COUNT(DISTINCT PT_NO), MCDP_CD`

* 환자 수 오름차순
* 동률인 경우 진료과 코드 오름차순

---

## 🎯 **요약**

| 항목    | 설명                             |
| ----- | ------------------------------ |
| 집계 기준 | 환자 수 → `COUNT(DISTINCT PT_NO)` |
| 취소 여부 | 문제에서 요구 없음 → 조건 미사용            |
| 정렬 기준 | 환자 수 ASC → 진료과 코드 ASC          |
