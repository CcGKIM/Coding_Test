## 문제 설명

- `N x M` 격자에서 출발점과 이동 방향을 정해 숫자를 이어붙임
- 이어붙인 수가 제곱수라면 후보에 포함
- 가능한 제곱수 중 최댓값을 출력, 없으면 `-1`

---

## 코드 동작 방식

1. **입력 처리**

   - `N, M` 크기의 숫자 격자를 입력받아 `matrix`에 저장

2. **숫자 생성 함수**

   - `make_number(i, j, k1, k2)`
   - `(i, j)`에서 시작해 `(k1, k2)` 방향으로 이동하면서 숫자를 이어붙임
   - 이어붙인 숫자가 제곱수이면 결과 리스트에 추가

3. **모든 경우 탐색**

   - 모든 출발점 `(i, j)`와 모든 방향 `(k1, k2)`를 고려
   - 가능한 모든 수를 생성하고 제곱수만 저장

4. **결과 출력**
   - 제곱수가 있으면 최댓값 출력
   - 없으면 `-1` 출력

---

## 시간 복잡도

- 출발점: `N * M`
- 방향: `19 * 19 = 361`
- 각 경로에서 생성: 최대 `max(N, M)`
- 전체: `O(N * M * 361 * max(N, M))`
- 예: `50 x 50` 격자 → 약 45만 연산 → 충분히 통과 가능

---

## 개선 포인트

- `math.isqrt()` 사용 시 부동소수점 오차 제거 가능
- `(k1, k2) = (0, 0)` 예외 처리는 생략 가능

---

## 개선된 코드

```python
from math import isqrt

N, M = map(int, input().split())
matrix = [list(input()) for _ in range(N)]

def make_number(i, j, k1, k2):
    temp = []
    curr = ''
    x, y = i, j
    while 0 <= x < N and 0 <= y < M:
        curr += matrix[x][y]
        num = int(curr)
        if isqrt(num) ** 2 == num:
            temp.append(num)
        x += k1
        y += k2
    return temp

val_set = set()

for i in range(N):
    for j in range(M):
        for k1 in range(-9, 10):
            for k2 in range(-9, 10):
                if k1 == 0 and k2 == 0:
                    continue
                for v in make_number(i, j, k1, k2):
                    val_set.add(v)

print(max(val_set) if val_set else -1)
```
