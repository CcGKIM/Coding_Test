# ⭐ Magic Star (백트래킹 / 제약 만족 문제)

## 📌 문제 개요

5×9 형태의 별 모양 격자에서
알파벳 **A ~ L (총 12개)** 을 각각 한 번씩 배치하여
아래 **6개의 선(line)** 에 포함된 알파벳 값의 합이 **모두 26**이 되도록 만드는 문제이다.

* `A = 1, B = 2, ..., L = 12`
* 일부 칸은 이미 알파벳이 채워져 있음
* `x` 로 표시된 칸은 채워야 할 칸
* `.` 은 무시되는 칸

---

## 🧠 핵심 아이디어

이 문제는 전형적인 **제약 만족 문제 (CSP, Constraint Satisfaction Problem)** 이다.

### 문제를 구성하는 요소

* **변수**: 별의 12개 위치
* **도메인**: 숫자 `1 ~ 12`
* **제약 조건**

  * 숫자는 중복 불가
  * 각 선(line)의 합은 정확히 `26`

👉 따라서
**DFS + 백트래킹 + 강력한 가지치기**가 핵심 전략이다.

---

## ✨ 풀이 전략

### 1️⃣ 입력 전처리

* 알파벳을 숫자로 변환
* 빈 칸(`x`)은 `0`으로 표시
* 이미 사용된 숫자는 `used` 집합에 저장

```python
A → 1, B → 2, ..., L → 12
```

---

### 2️⃣ 조건(선) 구조화

6개의 선을 미리 정의한다.

```text
c1 ~ c6 : 각각 4개의 좌표로 구성
각 선의 합 = 26
```

```python
condition_dict["c1"] = [(0,4), (1,3), (2,2), (3,1)]
...
```

또한 **각 좌표가 어떤 조건에 속하는지** 역방향 매핑을 만든다.

```python
loc_condition[(x, y)] = ["c1", "c4", ...]
```

👉 이 구조 덕분에
**숫자를 하나 놓을 때 관련된 선만 검사**할 수 있다.

---

### 3️⃣ 가지치기 (Pruning) — 핵심

숫자 하나를 놓을 때마다 다음을 검사한다.

#### 🔹 부분합 검사

* 아직 빈 칸이 남아 있는데
* 현재 합이 이미 `26 이상`이면 ❌

#### 🔹 완성 검사

* 해당 선이 모두 채워졌는데
* 합이 `26이 아니면` ❌

```python
if Flag and val >= 26:
    return False

if not Flag and val != 26:
    return False
```

👉 이 조건으로 탐색 공간이 **폭발적으로 줄어든다**.

---

### 4️⃣ DFS + 백트래킹

* 아직 채워지지 않은 위치에
* 사용하지 않은 숫자 중 하나를 시도
* 조건을 만족하면 재귀 호출
* 실패 시 원상 복구

```python
def dfs(cnt):
    if cnt == N:
        정답 처리
        return
```

---

## ✅ 전체 코드

```python
import copy

board = []

for _ in range(5):
    board.append(list(input()))

loc = []
used = set()

for i in range(5):
    for j in range(9):
        if board[i][j] != '.':
            if board[i][j] == 'x':
                board[i][j] = 0
            else:
                board[i][j] = ord(board[i][j]) - ord('A') + 1
                used.add(board[i][j])
            loc.append((i, j))

condition_dict = {
    "c1": [(0,4), (1,3), (2,2), (3,1)],
    "c2": [(3,1), (3,3), (3,5), (3,7)],
    "c3": [(0,4), (1,5), (2,6), (3,7)],
    "c4": [(1,1), (2,2), (3,3), (4,4)],
    "c5": [(1,7), (2,6), (3,5), (4,4)],
    "c6": [(1,1), (1,3), (1,5), (1,7)],
}

loc_condition = {}
for key, value in condition_dict.items():
    for v in value:
        loc_condition.setdefault(v, []).append(key)

N = len(loc)
answer = None

def is_available(curr, num):
    for condition in loc_condition[curr]:
        val = num
        has_empty = False

        for x, y in condition_dict[condition]:
            if (x, y) == curr:
                continue
            if board[x][y] == 0:
                has_empty = True
            else:
                val += board[x][y]

        if has_empty and val >= 26:
            return False
        if not has_empty and val != 26:
            return False

    return True

def dfs(cnt):
    global answer
    if answer:
        return

    if cnt == N:
        if all(sum(board[x][y] for x, y in v) == 26 for v in condition_dict.values()):
            answer = copy.deepcopy(board)
        return

    x, y = loc[cnt]
    if board[x][y] == 0:
        for num in range(1, 13):
            if num not in used and is_available((x, y), num):
                board[x][y] = num
                used.add(num)
                dfs(cnt + 1)
                board[x][y] = 0
                used.remove(num)
    else:
        dfs(cnt + 1)

dfs(0)

for i in range(5):
    for j in range(9):
        if answer[i][j] != '.':
            answer[i][j] = chr(ord('A') + answer[i][j] - 1)

for row in answer:
    print(''.join(row))
```

## ⏱️ 시간 & 공간 복잡도

### 시간 복잡도

* 최악: `O(12!)`
* 실제: **강력한 가지치기로 매우 빠르게 수렴**

### 공간 복잡도

* `O(12)` (재귀 깊이 + 방문 정보)

---

## 💡 개선 포인트

* 탐색 순서를 **제약이 많은 칸부터** 배치하면 더 빨라짐
* `used`를 비트마스크로 바꾸면 성능 개선 가능
* `deepcopy` 대신 즉시 출력하면 메모리 절약 가능

---

## 🎯 정리

* 이 문제는 **백트래킹 + 제약 조건 처리의 교과서적인 예제**
* 조건을 미리 구조화하고
* 부분합 기반 가지치기를 적용한 것이 핵심
* 코딩 테스트 및 면접에서 **CSP 설명용 예시**로 매우 좋음
