# 🧠 LRU Cache (LeetCode 146)

## 📌 문제 개요

LRU Cache(Least Recently Used Cache)는
**가장 오래 사용되지 않은 데이터를 먼저 제거하는 캐시 정책**이다.

요구 사항은 다음과 같다.

* `get(key)` :

  * key가 존재하면 해당 value 반환
  * 없으면 `-1` 반환
  * 접근된 key는 **가장 최근 사용 상태**로 갱신
* `put(key, value)` :

  * key가 존재하면 value 갱신 + 최근 사용 처리
  * 존재하지 않으면 새로 삽입
  * capacity 초과 시 **가장 오래 사용된 key 제거**
* `get`, `put` 모두 **O(1)** 시간 복잡도

---

## 💡 핵심 아이디어

LRU Cache를 O(1)로 구현하려면 **두 자료구조를 결합**해야 한다.

### 1️⃣ HashMap (dict)

* `key → Node` 매핑
* key 접근을 O(1)로 처리

### 2️⃣ Doubly Linked List (이중 연결 리스트)

* 사용 순서 관리
* 가장 최근 사용: `head` 바로 뒤
* 가장 오래된 사용: `tail` 바로 앞
* 노드 삭제 / 이동을 O(1)로 처리

👉 **dict는 “찾기”, 리스트는 “순서 관리” 역할**

---

## 🧱 자료구조 설계

```text
[HEAD] ⇄ [최근 사용 Node] ⇄ ... ⇄ [LRU Node] ⇄ [TAIL]
```

* `head`, `tail`은 **더미 노드**
* 실제 데이터는 head와 tail 사이에 위치
* eviction 대상은 항상 `tail.prev`

---

## 🧩 구현 코드

```python
class Node:
    def __init__(self, key, value):
        self.key = key
        self.value = value
        self.prev = None
        self.next = None


class LRUCache:
    def __init__(self, capacity: int):
        self.capacity = capacity
        self.cache = {}  # key -> Node
        self.head = Node(0, 0)
        self.tail = Node(0, 0)

        self.head.next = self.tail
        self.tail.prev = self.head

    def _remove(self, node):
        prv, nxt = node.prev, node.next
        prv.next = nxt
        nxt.prev = prv

    def _add_front_node(self, node):
        node.prev = self.head
        node.next = self.head.next
        self.head.next.prev = node
        self.head.next = node

    def get(self, key: int) -> int:
        if key not in self.cache:
            return -1

        node = self.cache[key]
        self._remove(node)
        self._add_front_node(node)
        return node.value

    def put(self, key: int, value: int) -> None:
        # 이미 존재하는 key 처리
        if key in self.cache:
            node = self.cache[key]
            node.value = value
            self._remove(node)
            self._add_front_node(node)
            return

        # capacity 초과 시 LRU 제거
        if len(self.cache) == self.capacity:
            lru_node = self.tail.prev
            self._remove(lru_node)
            del self.cache[lru_node.key]

        new_node = Node(key, value)
        self.cache[key] = new_node
        self._add_front_node(new_node)
```

---

## 🔍 주요 함수 설명

### `_remove(node)`

* 현재 노드를 연결 리스트에서 제거
* 앞/뒤 노드를 직접 연결

```python
prv.next = nxt
nxt.prev = prv
```

---

### `_add_front_node(node)`

* 노드를 **가장 최근 사용 위치(head 바로 뒤)**에 삽입

---

### `get(key)`

* cache에서 Node 조회
* 사용 순서 갱신 (remove → add_front)
* value 반환

---

### `put(key, value)`

* key가 존재하면:

  * value 갱신
  * 최근 사용 처리
* key가 없으면:

  * capacity 초과 시 LRU 제거
  * 새 노드 추가

---

## ⏱ 시간 / 공간 복잡도

| 연산    | 시간 복잡도 |
| ----- | ------ |
| `get` | O(1)   |
| `put` | O(1)   |

* HashMap + Doubly Linked List 조합 덕분에 모든 연산 O(1)

---

## 🧠 핵심 포인트 정리

* `prev`, `next`는 **Node 객체 참조**
* `cache`에는 반드시 **key → Node**
* eviction 대상은 항상 `tail.prev`
* 기존 key 처리 분기 없으면 **버그 발생**
