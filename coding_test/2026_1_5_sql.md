# 동물 이름 개수 구하기

## 문제 설명

동물 보호소에 들어온 동물 중 이름이 있는 동물의 **고유한 이름 개수**를 구하는 SQL 쿼리입니다.

## 요구사항

- `ANIMAL_INS` 테이블에서 조회
- 이름이 NULL이 아닌 동물만 카운트
- 중복된 이름은 하나로 처리 (DISTINCT)

## 테이블 구조

### ANIMAL_INS
| Column | Type | Description |
|--------|------|-------------|
| ANIMAL_ID | VARCHAR | 동물 아이디 |
| ANIMAL_TYPE | VARCHAR | 동물 종류 |
| DATETIME | DATETIME | 보호 시작일 |
| INTAKE_CONDITION | VARCHAR | 보호 시작 시 상태 |
| **NAME** | VARCHAR | 이름 |
| SEX_UPON_INTAKE | VARCHAR | 성별 및 중성화 여부 |

## SQL 쿼리

```sql
SELECT COUNT(DISTINCT NAME) AS count
FROM ANIMAL_INS
WHERE NAME IS NOT NULL;
```

## 쿼리 설명

### 1. `WHERE NAME IS NOT NULL`
- NULL 값을 가진 레코드 제외
- 이름이 있는 동물만 필터링

### 2. `COUNT(DISTINCT NAME)`
- `DISTINCT`: 중복된 이름 제거
- `COUNT()`: 고유한 이름의 개수 집계

### 3. `AS count`
- 결과 컬럼명을 `count`로 지정

## 예제

### Input Data (ANIMAL_INS)
| ANIMAL_ID | NAME | DATETIME |
|-----------|------|----------|
| A001 | Lucy | 2023-01-01 |
| A002 | Lucy | 2023-01-02 |
| A003 | Max | 2023-01-03 |
| A004 | NULL | 2023-01-04 |
| A005 | Bella | 2023-01-05 |

### Output
| count |
|-------|
| 3 |

**설명:**
- Lucy (중복 제거) → 1개
- Max → 1개
- Bella → 1개
- NULL (제외)
- **총 3개**

## 핵심 개념

### COUNT vs COUNT(DISTINCT)

```sql
-- 전체 이름 개수 (중복 포함, NULL 제외)
SELECT COUNT(NAME) FROM ANIMAL_INS;

-- 고유한 이름 개수 (중복 제거, NULL 제외)
SELECT COUNT(DISTINCT NAME) FROM ANIMAL_INS;

-- 전체 레코드 개수 (NULL 포함)
SELECT COUNT(*) FROM ANIMAL_INS;
```

### NULL 처리

| 조건 | 설명 |
|------|------|
| `WHERE NAME IS NULL` | 이름이 없는 동물 |
| `WHERE NAME IS NOT NULL` | 이름이 있는 동물 |
| `WHERE NAME = NULL` | ❌ 잘못된 문법 |

## 참고사항

- `COUNT()` 함수는 자동으로 NULL을 제외하지만, 명시적으로 `WHERE`로 필터링하는 것이 가독성이 좋습니다
- `DISTINCT`는 `COUNT()` 내부에 사용하여 중복을 제거합니다
