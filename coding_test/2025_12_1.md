# 📌 BOJ — 구간 정렬 가능 위치 구하기

**정렬 후 각 원소가 위치할 수 있는 최소·최대 인덱스**

---

## 🚀 문제 요약

길이 `N`인 수열이 주어진다.
각 원소는 **실제 값이 아닌**, 다음과 같은 **구간(range)** 형태이다:

```
ai ± bi  →  [ai - bi, ai + bi]
```

각 원소는 구간 내의 *어떤 실수라도* 될 수 있다.

수열을 정렬한다고 했을 때,
**각 원소가 가질 수 있는 인덱스의 최솟값과 최댓값**을 구하는 문제.

---

## 🎯 핵심 아이디어

각 원소 `i`는 다음 두 구간을 가진다:

```
Li = ai - bi    # 최소 가능 값
Ri = ai + bi    # 최대 가능 값
```

정렬 후 원소 i의 위치는 다음 두 조건에 의해 결정된다.

---

### ✅ 1. i가 “최대로 뒤로 갈 수 있는 위치”

i가 최대로 큰 값(Ri)을 택했다고 가정한다.

그때 앞에 올 수 있는 j는:

```
Lj ≤ Ri
```

→ 즉, **j의 최소값이 i의 최대보다 작거나 같다면**
→ j는 i보다 앞에 올 수도 있다.

이 j의 개수를 k라고 하면,

```
i의 가능한 최대 위치 = k + 1
```

즉,
**max_index = bisect_right(min_arr, Ri)**

---

### ✅ 2. i가 “최대로 앞으로 갈 수 있는 위치”

i가 최소값(Li)을 택했다고 가정한다.

i보다 뒤에 꼭 가야 하는 j는:

```
Rj < Li
```

→ 즉, **j의 최대값이 i의 최소보다 작다면**
→ j는 i보다 앞에 올 수 없다. (i가 무조건 뒤)

이 j의 개수를 m이라 하면,

```
i의 가능한 최소 위치 = m + 1
```

즉,
**min_index = bisect_left(max_arr, Li) + 1**

---

## 🔍 왜 이 방식이 맞는가?

이 문제는 개별 원소 i와 원소 j의 쌍을 직접 비교할 필요가 없다.

우리가 필요한 것은:

* "나보다 앞에 올 **수 있는** 원소가 몇 개인가?"
* "나보다 앞에 올 **수 없는** 원소가 몇 개인가?"

즉 **순위 통계(Order Statistics)** 문제이다.

따라서 원소 쌍 (Li, Ri)의 대응 관계가 사라져도
전체 Li, 전체 Ri를 따로 정렬해서 조회하면 정확히 계산된다.

---

## 🧠 시간 복잡도

```
정렬: O(N log N)
각 원소 이분 탐색: O(log N)
총합: O(N log N)
```

N이 큰 입력에서도 충분히 통과한다.

---

## 🧪 예시

입력

```
3
314 25
255 140
400 1
```

구간변환

```
[289, 339]
[115, 395]
[399, 401]
```

정렬 위치 범위는 다음처럼 계산된다.

---

## 🧾 정답 코드 (Python)

```python
from bisect import bisect_left, bisect_right

N = int(input())

arr = []
min_arr = []
max_arr = []

for _ in range(N):
    x, y = map(int, input().split())
    arr.append((x - y, x + y))
    min_arr.append(x - y)
    max_arr.append(x + y)

min_arr.sort()
max_arr.sort()

for Li, Ri in arr:
    # i보다 크거나 같게 앞에 올 수 있는 원소의 개수
    max_index = bisect_right(min_arr, Ri)
    
    # i보다 앞에 절대 올 수 없는 원소 개수
    min_index = bisect_left(max_arr, Li) + 1
    
    print(min_index, max_index)
```

---

## 🏁 마무리

이 문제의 핵심은 **값의 확정이 아니라 범위의 순위 비교**이다.
정렬 후 가능한 위치를 찾기 위해 “전체 최소값 배열”, “전체 최대값 배열”을 따로 정렬한 뒤
이분 탐색으로 앞·뒤에 가능한 원소의 개수를 세는 방식이 가장 효율적이다.
