# 🧮 트리 + DP 문제 풀이 (Python)

이 코드는 다음 조건을 만족하는 **가중치 독립집합(Independent Set)** 최대 합을 구하는 알고리즘이다.

* 주어진 노드 값들(nodes)을 정점으로 하는 그래프를 만든다.
* 두 노드의 값 차이가 diff 집합 안에 있으면 두 노드를 연결한다.
* 만들어진 그래프는 여러 개의 트리(또는 포레스트)가 된다.
* 각 트리에 대해 **트리 DP (Tree DP)** 로 독립집합 최대 가중치 합을 계산한다.

---

## 📌 문제 접근 방식

1. **노드 값 입력**
2. **허용되는 차이값(diff) 입력**
3. **모든 노드 쌍(i, j)에 대해 |nodes[i] - nodes[j]| 가 diff 안에 있으면 간선 생성**
4. 그래프는 항상 순환이 없으므로(문제 조건상) 트리 또는 포레스트가 된다.
5. 각 트리에 대해 DP 수행:

   * `dp[node][0]`: node를 선택하지 않은 경우
   * `dp[node][1]`: node를 선택한 경우
6. 트리 전체를 DFS로 돌며 독립집합 최대 가중치 계산

---

## 🧠 알고리즘 설명

### **트리 DP 점화식**

* 현재 노드를 **선택하지 않는 경우**

  ```
  not_select = Σ max(dp[child][0], dp[child][1])
  ```
* 현재 노드를 **선택하는 경우**

  ```
  select = node_value + Σ dp[child][0]
  ```

즉,
노드를 선택하면 자식은 선택 불가
노드를 선택 안 하면 자식은 선택/미선택 중 더 큰 값을 취해도됨

## 📎 전체 코드

```python
from collections import defaultdict

N, M = map(int, input().split())

tree = defaultdict(list)

nodes = []
diffs = set()

for _ in range(N):
    x = int(input())
    nodes.append(x)

for _ in range(M):
    x = int(input())
    diffs.add(x)

# 간선 생성
for i in range(N):
    for j in range(i + 1, N):
        curr_node = nodes[i]
        target_node = nodes[j]

        curr_diff = abs(target_node - curr_node)
        if curr_diff in diffs:
            tree[i].append(j)
            tree[j].append(i)

visited = set()

def tree_dp(index, visited):
    # dp[index][0]: not select
    # dp[index][1]: select

    visited.add(index)

    not_select = 0
    select = nodes[index]

    for child in tree[index]:
        if child not in visited:
            a, b = tree_dp(child, visited)
            not_select += max(a, b)
            select += a

    return not_select, select


answer = 0

for i in range(N):
    if i not in visited:
        val_one, val_two = tree_dp(i, visited)
        answer = max(answer, max(val_one, val_two))

print(answer)
```

## ⏱ 시간복잡도

### 그래프 구성

* 모든 쌍(i, j) 확인 → **O(N²)**
* diff 조회는 set → O(1)

### DP

* 그래프는 트리 구조 → 총 **O(N)**

### 전체

```
O(N²) + O(N) ≈ O(N²)
```

N이 너무 크면 병목 구간은 **노드 간 차이 계산 부분**임.

---

## ✨ 개선할 수 있는 부분

1. **현재: 모든 쌍(i, j)을 검사 → O(N²)**
   → N이 커지면 매우 비효율적.

2. **개선 아이디어**

   * nodes를 정렬하고 two-pointer로 diff 검사
   * diff가 작으면 Binary Search로 후보 노드를 빠르게 찾기
   * diff가 많으면 hashmap 역인덱스 구성

예)

```python
value_to_index = defaultdict(list)
for i, val in enumerate(nodes):
    value_to_index[val].append(i)
```
