# 🛒 PRODUCT × OFFLINE_SALE 매출 집계 + WITH(CTE) 안정적 사용법 정리

이 문서는 PRODUCT 테이블과 OFFLINE_SALE 테이블을 조인하여
**제품별 총 매출(SALES)을 계산하는 SQL 문제**를 해결한 코드와,
그 과정에서 흔히 발생하는 **WITH(CTE) 오류(중복 컬럼 문제)**까지 함께 정리한 GitHub README용 설명입니다.

---

## 📌 문제 요구사항

* 각 상품 코드(PRODUCT_CODE)별 총 매출액 계산
* 매출 공식:

  ```
  SALES = PRICE × SALES_AMOUNT
  ```
* 매출액 내림차순 정렬
* 매출액이 같다면 PRODUCT_CODE 오름차순 정렬

---

# ✅ 정답 SQL 쿼리 (WITH 없이)

```sql
SELECT 
    p.PRODUCT_CODE,
    SUM(p.PRICE * o.SALES_AMOUNT) AS SALES
FROM PRODUCT p
JOIN OFFLINE_SALE o 
      ON p.PRODUCT_ID = o.PRODUCT_ID
GROUP BY p.PRODUCT_CODE
ORDER BY SALES DESC, 
         p.PRODUCT_CODE ASC;
```

---

# 🧠 WITH(CTE) 사용 시 주의할 점

WITH(CTE)는 임시 테이블을 만들어 뒤에서 사용할 수 있도록 해주는 기능이다.

✔ 하지만 CTE는 **컬럼 이름이 모두 고유(unique)**해야 한다.
✔ `SELECT *`로 조인을 할 경우 **중복 컬럼 이름이 발생한다.**

예: PRODUCT 테이블과 OFFLINE_SALE 테이블 모두 `PRODUCT_ID`를 갖고 있음.

따라서 다음과 같은 코드는 오류가 난다.

```sql
WITH JOINED_SALE AS (
    SELECT *
    FROM PRODUCT p
    JOIN OFFLINE_SALE o ON p.PRODUCT_ID = o.PRODUCT_ID
)
SELECT *
FROM JOINED_SALE;
```

오류 메시지:

```
Duplicate column name 'product_id'
```

이는 조인된 결과에서 PRODUCT_ID 컬럼이 **중복되어 존재하기 때문**이다.

---

# 🔥 해결 방법: 필요한 컬럼만 명시적으로 선택하기

### ✔ 올바른 CTE 버전(중복 없이 구성)

```sql
WITH JOINED_SALE AS (
    SELECT 
        p.PRODUCT_CODE,
        p.PRICE,
        o.SALES_AMOUNT
    FROM PRODUCT p
    JOIN OFFLINE_SALE o 
        ON p.PRODUCT_ID = o.PRODUCT_ID
)
SELECT *
FROM JOINED_SALE
ORDER BY PRICE * SALES_AMOUNT DESC, PRODUCT_CODE ASC;
```

하지만 실제 총 매출액을 구하려면 아래처럼 SUM + GROUP BY가 필요하다.

---

# 🏆 최종 정답 WITH(CTE) + GROUP BY 버전

```sql
WITH JOINED_SALE AS (
    SELECT 
        p.PRODUCT_CODE,
        SUM(p.PRICE * o.SALES_AMOUNT) AS SALES
    FROM PRODUCT p
    JOIN OFFLINE_SALE o 
        ON p.PRODUCT_ID = o.PRODUCT_ID
    GROUP BY p.PRODUCT_CODE
)
SELECT *
FROM JOINED_SALE
ORDER BY SALES DESC, PRODUCT_CODE ASC;
```

---

# 📚 WITH(CTE) 사용 요약

| 항목             | 설명                         |
| -------------- | -------------------------- |
| WITH(CTE) 목적   | 복잡한 쿼리를 임시 테이블처럼 단계별로 나누기  |
| CTE 내부 규칙      | 컬럼명이 모두 **유일(unique)**해야 함 |
| SELECT * 사용 문제 | 조인 시 중복 컬럼이 있으면 CTE 생성 불가  |
| 해결책            | 필요한 컬럼만 명시적으로 선택하기         |

---

# 🔍 Tips

✔ **SELECT * 는 조인 + CTE에서는 거의 금지**
✔ 컬럼명이 충돌할 가능성이 있는 경우 반드시 Alias 사용
✔ CTE는 복잡한 집계·전처리 상황에서 구조를 깔끔하게 유지하는 데 매우 유용함
