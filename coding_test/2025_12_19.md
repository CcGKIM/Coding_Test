## 📌 문제 개요

문자열에 여러 쌍의 괄호 `()`가 포함되어 있을 때,
**하나 이상의 괄호 쌍을 제거해서 만들 수 있는 모든 서로 다른 문자열**을
**사전순으로 출력**하는 문제다.

* 괄호는 **짝이 맞는 것끼리만 제거**
* **원본 문자열은 제외**
* 중복 결과는 한 번만 출력

---

## 🧠 핵심 아이디어

이 문제의 핵심은 딱 2가지야.

### 1️⃣ 괄호 쌍을 먼저 정확히 찾기

* 스택을 이용해서 `(` 와 `)` 의 **인덱스 쌍**을 구한다.

### 2️⃣ 괄호 쌍 선택/비선택 → 비트마스크

* 괄호 쌍이 `k`개면
  → 각 괄호를 **지울지 말지** 결정하는 모든 경우의 수는 `2^k`
* 단, **아무 것도 안 지우는 경우(mask = 0)** 는 제외

---

## 💡 전체 알고리즘 흐름

```text
1. 스택으로 괄호 쌍의 인덱스 저장
2. 비트마스크로 제거할 괄호 조합 탐색
3. 선택된 괄호 쌍의 인덱스를 빈 문자열로 치환
4. 결과 문자열을 set에 저장 (중복 제거)
5. 정렬 후 출력
```

---

## 🧾 코드

```python
letter = input()

stack = []
pairs = []
candidates = set()

# 1. 괄호 쌍 인덱스 찾기
for idx, value in enumerate(letter):
    if value == '(':
        stack.append(idx)
    elif value == ')':
        left = stack.pop()
        pairs.append((left, idx))

# 2. 괄호 제거 조합 (비트마스크)
for mask in range(1, 1 << len(pairs)):
    curr_word = list(letter)

    for i in range(len(pairs)):
        if mask & (1 << i):
            left, right = pairs[i]
            curr_word[left] = ''
            curr_word[right] = ''

    candidates.add(''.join(curr_word))

# 3. 정렬 후 출력
for candidate in sorted(candidates):
    print(candidate)
```

---

## ⏱ 시간 복잡도

* 괄호 쌍 개수: `k`
* 가능한 경우의 수: `2^k - 1`
* 문자열 길이: `N`

👉 **시간 복잡도**

```
O(2^k × N)
```

👉 **공간 복잡도**

```
O(2^k × N)   (결과 문자열 저장)
```

> ⚠️ 그래서 이 문제는 **괄호 쌍이 많지 않다는 전제**가 있어야 풀 수 있음

---

## 🔍 왜 set을 쓰는가?

괄호 제거 순서가 달라도 **결과 문자열이 같아질 수 있음**

```text
(a(b))  
→ 바깥 괄호 제거  
→ 안쪽 괄호 제거  
```

이런 중복을 제거하기 위해 `set`이 필수다.

## 🚀 개선 / 다른 관점

### ✔ 현재 풀이의 장점

* 구현이 직관적
* 괄호 문제의 정석 (스택 + 비트마스크)
* 디버깅 쉬움

### ❌ 굳이 안 쓰는 최적화

* DFS로 조합 생성 가능
* 문자열 누적 방식으로 메모리 줄이기 가능

👉 **하지만 코테 기준에서는 지금 풀이가 가장 깔끔하고 안전**
